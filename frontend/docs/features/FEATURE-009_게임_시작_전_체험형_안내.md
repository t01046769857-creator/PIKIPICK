# FEATURE-009 — 독립 규칙 연습 메뉴

- 변경일: 2026-11-12
- 목적: 네 번째 청개구리 카드를 규칙 연습으로 교체하고 일반 게임은 선택 즉시 시작한다.
- 변경 파일: `App.tsx`, `components/GameRulePractice.tsx`, `components/GameRulePractice.css`, `game/types.ts`, `game/reducer.ts`, `game/reducer.test.ts`, `docs/USER_FLOW.md`.

## 구현과 화면 변화

선택 화면의 네 번째 요소를 기존 `mode-card` 클래스의 규칙 연습 버튼으로 교체했다. 기존 그리드 순서와 카드 스타일은 유지한다. 일반 이기기·지기·비기기의 `SELECT_MODE`는 피키 손을 생성하고 곧바로 `PLAYING`으로 이동한다. 별도 규칙 확인·준비 화면을 렌더링하지 않는다.

규칙 연습은 새로운 GameMode가 아니라 `RULE_PRACTICE` 화면 단계다. `OPEN_RULE_PRACTICE`는 선택 화면에서만 허용하며 모드와 상대 손은 null이다. 이기기·지기·비기기 각각 바위·가위·보, 총 9개 예제를 제공한다. 기존 `isSuccessful` 함수로 손 그림 선택을 판정하고 정답 또는 재시도 안내를 표시한다. 정답 후 다음 화살표를 활성화하고 이전 예제의 선택을 보존한다. 큰 화살표를 사용하며 마지막 “연습 완료 →”와 “건너뛰기 ⏭”는 모두 게임 선택으로 돌아간다. 다시 들어오면 첫 예제부터 시작한다.

연습 답안은 컴포넌트 내부 상태다. 실제 게임 입력을 제출하거나 별·파티·누적 기록을 바꾸지 않는다. 기존 READY/INSTRUCTION reducer 액션은 호환성을 위해 남기되 현재 사용자 화면에서는 거치지 않는다.

## 영향 범위

청개구리 카드는 최신 요청에 따라 화면에서 제거했다. 세 일반 모드 판정, 보상 로직, 캐릭터 에셋과 애니메이션, 인트로, 실제 게임 UI, 공통 CSS는 이번 작업에서 변경하지 않았다. 연습 전용 CSS만 화살표 크기를 추가했다. 이전 작업의 미커밋 변경을 보존했다.

## 검증과 남은 확인

`npm run build`, `npm test`(3개 파일, 15개 테스트), `git diff --check`가 통과했다. 세 모드 즉시 시작, 중복 모드 선택 무시, 연습의 독립 상태와 실제 게임 입력 차단, 선택 화면 복귀 및 누적 기록 보존을 테스트했다. 기존 판정·보상 테스트도 통과했다.

수정 전후 화면 캡처는 확보하지 못했다. 실제 브라우저의 손 그림·화살표·건너뛰기 조작과 모바일에서 네 번째 카드의 실제 크기·줄바꿈 확인은 남아 있다.
