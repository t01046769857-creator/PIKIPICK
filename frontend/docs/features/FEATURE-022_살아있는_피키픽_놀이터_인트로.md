# FEATURE-022 · 살아 있는 피키픽 놀이터 인트로

## 목적

기존 피키 캐릭터·로고·놀이터 배경과 손잡기 시작 흐름을 유지하면서, 넓은 화면에서도 피키가 놀이터 안에 서 있는 듯 보이도록 인트로의 공간감과 대기 동작을 다듬었다.

## 변경 사항

- 놀이터 배경을 비율을 왜곡하는 `fill` 방식에서 `cover`와 하단 기준 정렬로 변경했다.
- 중앙 캐릭터 캔버스의 최대 크기를 620px로 제한하고, 넓은 화면에서는 주변 풍경이 보이도록 안전 영역을 넓혔다.
- 손 내밀기 자세의 발밑에 약한 타원 그림자를 배치했다.
- 두 말풍선 중 대표 안내 하나만 남기고 문구를 `내 손 잡아볼래?`로 통일했다.
- 손 내밀기 조합 전체에는 5.4초 주기의 미세한 호흡·고개 기울임 동작을 적용했다.
- 분리된 손 레이어에는 3.6초 주기의 아주 작은 초대 동작과 약한 반짝임을 적용했다.
- 손 클릭 뒤에는 기존 화면 전환 전에 짧은 반가움 동작이 보이도록 했다.

## 에셋과 애니메이션 제약

`piki-intro-play-start-body.png`와 `piki-intro-play-start-hand.png`는 같은 1323×1189 캔버스를 공유하므로 전체 조합 이동과 손 안내 애니메이션에 사용했다. 눈 깜빡임 리그 PNG는 손 내밀기 조합과 캔버스·정렬 기준이 다르므로 대기 화면에 억지로 겹치지 않았다. 기존 등장 단계의 눈 깜빡임은 유지된다.

## 접근성 및 반응형

실제 손 위치에 맞춘 기존 투명 버튼과 키보드 포커스 스타일을 유지했다. 손 안내, 손 초대, 대기 동작은 `prefers-reduced-motion`에서 정지한다. 모바일에서는 기존 손 터치 범위를 유지한다.

## 보호 범위

게임 선택, 가위바위보 모드·판정, 별 보상, 비밀나라 대시보드, FastAPI, TiDB는 변경하지 않았다.
