# FEATURE-036 · LXP 보물 진열장

- 상단 `내가 발견한 보물`을 독립 진열 공간·받침대·조명·그림자가 있는 보물 진열장으로 변경했다.
- 실제 획득 상태만 `orderedBadgeConcepts`에서 가져와 최대 3개를 표시하고, 최근 배지를 앞쪽·큰 크기로 강조한다.
- 획득 배지가 없으면 빈 진열장 상태를 표시한다.
- 기존 배지 ID, 조건, 배지함, 모험길, API와 DB는 변경하지 않았다.
- 성공 횟수 변화로 진열장이 갱신될 때 새 배지 등장 애니메이션을 실행한다.

검증: `npm.cmd run build`, Vitest 57개, `git diff --check`, Chrome 1440×900 실제 캡처 확인.
