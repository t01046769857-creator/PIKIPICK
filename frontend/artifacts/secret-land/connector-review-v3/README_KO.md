# PIKIPICK 연결 배경 v3 — 최종 전달 패키지 (검수용)

이 패키지는 **원본 3장 + 수정 후보 2장 + 실제 이음새 확대 이미지 + 전체 배치 미리보기 + 코덱스 프롬프트**를 한 번에 담았습니다.

## 실제 처리
- 왼쪽 원본 3100×900의 x=0~2599 픽셀은 완전 보존; x=2600~3099의 500px만 보정
- 오른쪽 원본 3500×900의 x=500~3499 픽셀은 완전 보존; x=0~499의 500px만 보정
- 기존 승인 다리 원본 2400×800은 절대 수정하지 않음
- x=3100 및 x=5500 경계에서는 승인 이미지 경계 픽셀을 정확히 일치시킴
- 전체를 새로 그린 생성물과 흰 여백이 있는 후보는 사용하지 않음

## 검수 중점 / 주의사항
- 픽셀 경계는 0 차이지만, 강둑·흙길의 그림 형태가 자연스럽게 이어진다는 의미는 아닙니다. 최종 확정품이 아닌 REVIEW 후보입니다.
- 연결부 500px에 왜곡/색 변화가 발생할 수 있으므로 previews 폴더 이미지에서 직접 판정하세요.
- 승인 다리는 world y=50~850에만 있고, 위아래 50px의 미리보기는 경계색을 단순 연장한 것이므로 게임에서 그대로 재생산하지 말고 확인하세요.
- route node 9 (3100,690)과 다리 위 시각적 도로 중앙 (~603.5)에는 여전히 차이가 있습니다. v3 에셋이 보행 경로 문제를 자동으로 해결하지는 않습니다.

## 파일 구조
- reference/: SHA 일치하는 3장 원본
- assets/: 2장 새 3100×900 / 3500×900 검수 후보
- previews/: 전체 배치, x3100, x5500의 경계 확대
- manifest.json: 좌표, 보정 영역, 주의사항
- CODEX_PROMPT_KO.md: 적용·검증 지시문
