# FEATURE-024 인트로 반응형 레이아웃 복구

## 목적

첫 화면에서 화면 비율에 따라 놀이터 통합 배경의 좌우 풍경이 잘리고, 피키와 손 안내 말풍선이 서로 다른 기준으로 배치되던 문제를 복구한다.

## 변경 파일

- `frontend/src/styles.css`

## 구현

- 4:3 계열의 태블릿 가로 화면(641px 이상, 4:3~3:2)에서는 놀이터 배경을 `contain`과 하단 기준으로 표시한다. 하나의 통합 배경 안에 있는 벤치, 미끄럼틀, 나무, 꽃과 길을 함께 보존한다.
- 세로형·작은 화면은 기존 `cover` 표시를 유지해 피키와 손잡기 영역을 우선하고, 과도한 빈 하늘 영역을 만들지 않는다.
- 피키 안전 영역을 기존 최대 폭으로 되돌리고 `box-sizing: border-box` 및 하단 여백을 적용해, 상단·하단 여백이 실제 무대 높이 밖으로 더해져 캐릭터가 아래로 밀리던 계산을 막았다.
- 손 안내 말풍선을 뷰포트 계산값 대신 피키 캔버스의 왼쪽·세로 위치 기준으로 배치했다. 따라서 화면 폭이 바뀌어도 말풍선과 실제 손이 함께 이동한다.

## 영향 범위

인트로 전용 CSS만 변경했다. 피키 손의 투명 버튼 좌표, 다음 화면 이동, 게임 UI, 비밀나라, FastAPI 및 TiDB 코드는 변경하지 않았다.

## 검증

- `npm test -- --run`: 10개 파일, 55개 테스트 통과
- `npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과
- `git diff --check`: 오류 없음(기존 CRLF 경고만 표시)
- 이 환경의 headless Chrome/Edge는 GPU 초기화 오류로 새 스크린샷을 생성하지 못했다. 따라서 1920×1080, 1440×900, 1366×768, 1024×768, 768×1024, 390×844, 360×800의 실제 육안 확인은 브라우저에서 추가로 진행해야 한다.
