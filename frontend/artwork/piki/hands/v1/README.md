## 기준 이미지와 생성 순서

`src/assets/characters/piki/references/PIKI_MASTER_A.png`와 `gestures/piki-rock.png`, `piki-scissors.png`, `piki-paper.png`를 먼저 직접 확인했다. 바위 생성에는 마스터와 세 기존 포즈를 사용했다. 가위에는 마스터·기존 가위·생성 바위를, 보에는 마스터·기존 보·생성 바위·생성 가위를 참조해 선과 질감을 맞췄다.

생성 직후 1254×1254 PNG는 `source-generated/`에 원형 보존했다. 최종 파일은 그 이미지 전체를 균일 축소하고 이동하여 등록했다. 비율 왜곡, 손 윤곽 마스크, 손가락 자르기, 원본 캐릭터 크롭은 하지 않았다. 배경 alpha를 유지했다. 생성 결과를 정확한 좌표로 등록하고 검수판을 만드는 재현 스크립트는 `Build-Review.ps1`이다. 이 스크립트는 게임 소스에 포함되지 않는다.

## 복원·보강한 부분

원본 손은 얼굴·팔과 합쳐져 있고 손목의 독립 경계가 없다. 따라서 아래는 생성 과정에서 새로 그려진 영역이다.

1. 세 동작의 손목 하단과 손바닥 연결 윤곽: 짧고 닫힌 손목 형태로 재구성.
2. 바위: 접힌 네 손가락과 엄지 겹침을 읽을 수 있도록 보강.
3. 가위: 두 펼친 손가락 외에 접힌 손가락·엄지를 표현해 토끼 귀만 보이는 형태와 구분.
4. 보: 펼친 네 손가락과 엄지를 분리하고 손가락 사이의 연결부를 완성.

흰색의 미세한 종이 질감, 짙은 갈색의 둥근 외곽선은 참조를 따랐지만 원본과 픽셀 단위로 동일하지 않다. 형상·선 굵기·기존 피키와의 조화는 사용자 시각 검수가 필요하다. 레이어 원본 PSD/AI는 생성되지 않았으며 PNG와 프롬프트·등록 정보를 보존한다. 향후 개별 손가락 변형에는 별도 레이어 작업이 필요하다.

## 검증

- 최종 PNG 3개가 모두 1024×1024, 32-bit RGBA임을 확인.
- 네 모서리 완전 투명, 공통 기준점이 손목 내부에 위치함을 검사.
- alpha 128 이상인 가시 윤곽의 경계가 안전 여백 안에 들어오는지 검사. 이 기준은 손 윤곽을 잘라내는 마스크로 사용하지 않는다.
- 최종 경계: 바위 `(281,417)~(750,879)`, 가위 `(294,242)~(712,879)`, 보 `(216,224)~(819,879)`.
- 비교 미리보기를 직접 열어 세 동작·손목 정렬·손가락과 외곽선의 잘림 여부를 확인.
- 원본 마스터와 기존 포즈 3개의 Git diff가 없음을 확인. 원본 해시는 `reference-sha256.json`에 기록.
- 게임 코드·assetMap·CSS에는 이번 단계의 변경 없음. 이미지 전용 작업이라 게임 빌드·테스트는 실행하지 않음.
