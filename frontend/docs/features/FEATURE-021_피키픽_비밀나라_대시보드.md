# FEATURE-021 · 피키픽 비밀나라 대시보드

## 목적

기존 메뉴의 `내 별`을 `피키픽 비밀나라`로 바꾸고, 아이가 숫자 점수 대신 탐험 지도·배지·다음 놀이 선택으로 자신의 경험을 확인하는 화면을 추가했다.

## 화면 흐름

`메뉴 → 피키픽 비밀나라 → 배지함 또는 놀이 선택`

- 배지함은 배지 도감으로 이동하며, 도감의 뒤로가기 버튼은 비밀나라로 복귀한다.
- 놀이 선택은 기존 전체 놀이 선택 화면으로 이동한다.
- 가위바위보를 고르면 기존 이기기·지기·비기기·규칙 연습 2×2 모드 선택 화면을 그대로 사용한다.

## 데모 상태

새 길 발견과 배지 획득 표시는 화면 메모리에만 있는 명시적 데모 상태다. 지도 속 비밀 장소를 누르면 새 공간과 관련 배지가 보이지만, FastAPI·TiDB·로컬 게임 기록을 읽거나 쓰지 않는다. 실패나 재시도 때문에 배지나 발견 장소를 제거하는 동작도 없다.

## 구성

- 상단: 나의 배지함 버튼
- 중앙: 가위바위보 들판과 숨겨진 이야기 숲이 있는 탐험 지도
- 하단: 전체 놀이 선택으로 이동하는 큰 버튼

배지 도감에는 첫 성공, 재도전, 실패 뒤 성공, 성공 누적, 새 놀이, 새 공간 발견 등 서로 다른 조건의 데모 배지를 표시한다. 가위바위보 승리 수와 교육적 성취 배지는 별도로 표현하며, 메인 지도에는 숫자 점수판을 표시하지 않는다.

## 보호 범위

기존 독립 미리보기(`lxp-preview.html`과 `src/preview/`)는 변경하거나 삭제하지 않았다. 기존 가위바위보 판정, 별 보상·기록, FastAPI 라우터, TiDB 스키마와 데이터는 변경하지 않았다.
