# FEATURE-054 — 비밀나라 피키 걷기 애니메이션 v2 검수·적용

## 목적

`PIKIPICK_walk_v2_8frames_REVIEW.zip`의 준비된 좌우 걷기 프레임을 검수하고, 비밀나라의 기존 이동 속도·경로·카메라·정지 에셋을 유지한 상태에서 이동 중 프레임만 교체한다.

## 검수 결과

- 대상: 오른쪽 4프레임, 왼쪽 4프레임.
- 모든 준비 프레임은 1254×1254 RGBA PNG이며 모서리 투명 상태를 확인했다.
- 오른쪽 프레임은 오른쪽을 향하고, 왼쪽 프레임은 왼쪽을 향한다.
- 모자·얼굴·가방·랜턴의 캐릭터 디자인이 일관된다.
- 준비본의 불투명 영역은 공통 하단 기준선에 맞고, 인접 프레임 조각이나 설명 문자 혼입은 확인되지 않았다.
- 포즈는 발을 번갈아 내딛는 순서로 구성되어 적용 가능 판정했다.
- `manifest.json`의 `review_only_not_approved_for_game` 표기는 자동 적용 금지 안내이므로, 위 픽셀·시각 검수 후 이 기능 범위에서 승인하여 적용했다.

## 적용 방식

| 상태 | 에셋 |
| --- | --- |
| 정지 | 기존 `piki-explorer-idle-front.png` |
| 오른쪽 이동 | `walk-v2/right/piki-walk-right-01~04.png` |
| 왼쪽 이동 | `walk-v2/left/piki-walk-left-01~04.png` |

`LxpSecretLandDashboard.tsx`에서 이동 방향별 4프레임 배열을 사용하며, 이동 거리가 20 월드 픽셀 누적될 때마다 다음 프레임으로 전환한다. 기존 `ADVENTURE_WALK_SPEED = 100`과 `requestAnimationFrame` 기반 위치 갱신은 변경하지 않았다. 따라서 프레임 재생 속도는 약 5프레임/초이며 속도와 독립적으로 튀지 않는다.

각 프레임은 1254×1254 공통 캔버스를 사용하고 실제 하단 지지 발 중심을 별도 `footAnchor`로 지정했다. 준비본의 기준선은 y=1198이며, 좌우 프레임의 x 기준점은 실제 하단 불투명 지지 영역을 스캔해 산출했다.

## 파일 및 보호 범위

- 신규 적용 에셋: `frontend/src/assets/characters/piki/adventure/walk-v2/left/`, `right/`의 PNG 8개.
- 기존 좌우 원본은 덮어쓰지 않고 `adventure/backups/pre-walk-v2/`에 보존했다.
- 월드 배경, Catmull-Rom 경로, 이동 속도, 카메라, 해금·재입장, 저장 로직, 정지 에셋은 변경하지 않았다.
- 별도 CSS 애니메이션·transition·회전·바운스 효과는 추가하지 않았다.

## 검증

- `npm.cmd run build`: 통과.
- `npm.cmd test -- --run`: 12개 파일, 63개 테스트 통과.
- 실제 `localhost:5173/play/world` 브라우저에서 검증했다.
- 데스크톱: 오른쪽 이동 중 `right-03 → right-04 → right-02`, 정지 후 idle 복귀를 확인했다. 왼쪽 이동 중 `left-01`과 정지 후 idle 복귀를 확인했다.
- 모바일 390×844: 왼쪽 이동 중 `left-03`, 정지 후 idle 복귀를 확인했다.
- 이동 중 계산된 이미지 애니메이션은 `none`이었고, 월드 캐릭터의 transition도 `none`이었다. 위치와 카메라 transform은 이동 중 연속적으로 갱신됐다.

## 남은 사항

브라우저 검증은 격리된 테스트 저장 상태에서 수행했으며, 실제 지면 접지의 최종 시각 판정은 각 배경 구간의 화면 캡처를 별도로 비교해야 한다. 이번 변경은 프레임 교체와 프레임별 접지 기준 적용까지만 포함한다.
