### PNG 검사 해석

- 모든 신규 PNG는 알파 채널을 가진 독립 512×512 파일입니다.
- 주 그림의 bbox가 캔버스 중앙에 작게 위치해 외곽 투명 여백이 큽니다. 이는 CSS `object-fit`만의 문제가 아니라 원본 캔버스 구성 문제입니다.
- `badge-art-02`, `03`, `07`, `10`, `18`, `26`, `34`는 실제 뷰어에서 인접 그림 조각이 확인되었습니다.
- 나머지 `혼입 의심` 항목은 알파 성분이 분리되어 있으나, 그림의 장식·그림자일 가능성과 인접 이미지일 가능성을 픽셀 의미까지 확정하려면 추가 수작업 검수가 필요합니다.
- 따라서 40개를 일괄 교체하거나 CSS 확대값만 추가하는 것은 안전하지 않습니다.

## 크기·그림체 불일치 원인

1. **PNG 캔버스/투명 여백**: 신규 PNG의 실제 알파 bbox가 512×512 중 약 11.0~15.1% 면적에 그쳐 화면에서 작게 보입니다.
2. **PNG 분리 오류**: 일부 파일은 가장자리 별도 성분이 있어 옆 배지 조각이 섞일 수 있습니다.
3. **디자인 외곽 크기 차이**: 파일마다 bbox 폭·높이가 다르고, 특히 01·08·33·40처럼 상대적으로 좁거나 낮은 그림은 동일 CSS 크기에서도 작게 보입니다.
4. **기존·신규 혼용**: 드래곤 알과 무지개 나비는 신규 `badge-art-02/03`이 아니라 256×256 기존 clean PNG를 사용합니다. 수정 궁전·보물상자는 512×512 신규 PNG를 사용합니다.
5. **CSS 임시 도형**: `moon-fox`, `starlight-key`, 대부분 `future-*`에는 이미지가 없고 `.lxp-secret__badge-art::before/after`가 표시됩니다(`LxpSecretLandDashboard.css:51-58`).
6. **매핑 누락/문서 불일치**: 현재 코드에는 `future-2`, `future-3`, `future-16`, `future-18`, `NEW_PATH` 매핑이 없습니다. 이전 FEATURE-050 문서에 적힌 일부 매핑과 현재 `badgeAssets.ts`가 다릅니다. 실제 동작 기준은 현재 코드입니다.
7. **렌더링 확대 규칙**: 도감에서는 `.lxp-secret__badge-grid--fantasy .lxp-secret__badge-art`에 `transform: scale(1.28)`와 이미지 `width/height: 140%`가 적용되지만, 원본 투명 여백과 256/512 파일 혼용을 해결하지는 못합니다(`LxpSecretLandDashboard.css:59-62`).

## 결론 및 후속 작업 범위

현재 문제는 단일 CSS 값이 아니라 다음 세 가지가 함께 발생한 결과입니다.

- 6개 런타임 배지와 36개 도감 콘셉트가 분리되어 있음
- 512×512 신규 PNG, 256×256 기존 clean PNG, CSS 도형이 동시에 사용됨
- 일부 신규 PNG에 인접 이미지 조각이 포함됨

후속 구현 전에는 다음을 먼저 승인·결정해야 합니다.

1. 런타임 6개 배지와 36개 미래 콘셉트의 자산 연결 정책
2. 기존 clean PNG를 512×512 공통 캔버스로 재정규화할지 여부
3. 혼입 확인/의심 PNG의 재분리 또는 재제작 여부
4. 실제 획득 조건이 없는 `future-*` 콘셉트에 이미지를 표시할지 여부
5. CSS 임시 도형을 제거할지, 미획득 실루엣 전용으로 유지할지 여부

이번 단계에서는 위 문제를 수정하지 않았으며, 배지 획득 데이터·순서·저장 상태·보물상자 동작도 변경하지 않았습니다.
