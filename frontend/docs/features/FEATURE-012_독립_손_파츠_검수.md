# FEATURE-012 — 독립 손 파츠 제작과 검수

- 날짜: 2026-11-12
- 목적: 피키 바위·가위·보를 공통 캔버스와 손목 기준점을 갖는 독립 이미지로 제작.
- 상태: 이미지 3개와 검수 자료 제작 완료, 사용자 시각 검수 대기. 게임 화면 적용 전.
- 파일: `src/assets/characters/piki/hands/`의 PNG 3개와 `hand-spec.json`, `artwork/piki/hands/v1/`의 생성 원본·프롬프트·등록 스크립트·비교 미리보기·제작 기록.

기존 마스터와 게임용 포즈를 시각적 참조로 내장 image_gen을 사용했다. 원본 크롭이 아니라 참조 기반 재제작이며, 가려진 손목 경계와 접힌 손가락 구분은 새로 복원·보강했다. 전체 생성 이미지를 균일 축소·이동해 최종 1024×1024 투명 PNG와 공통 손목 기준점 `(512,820)`에 맞췄다. 손 윤곽 마스크나 비율 변형은 사용하지 않았다.

상세 사양, 복원 영역, 사용 프롬프트, 검증 결과, 미검수 항목은 [제작·검수 기록](../../artwork/piki/hands/v1/README.md)에서 확인한다. 비교 미리보기에는 투명도 확인용 체크무늬와 기준선이 있으며 실제 파츠에는 포함하지 않는다.

원본 캐릭터 이미지와 기존 코드·UI·규칙·보상 기능은 이번 단계에서 변경하지 않았다. PNG 크기·투명 모서리·기준점·안전 여백을 검사하고 미리보기를 직접 확인했다. 앱에 연결하지 않아 게임 빌드·동작 검증은 이번 단계에 해당하지 않는다. 다음 단계는 사용자 검수이며, 승인 후에만 공통 컴포넌트 적용을 진행한다.
