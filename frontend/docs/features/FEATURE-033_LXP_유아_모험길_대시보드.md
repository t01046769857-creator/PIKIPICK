# FEATURE-033 · 유아 LXP 모험길 대시보드

## 변경 목적

기존 `SecretLandDashboard`의 데모 발견 상태를 실제 클라이언트 기록과 구분하고, 아이가 경험한 놀이를 모험길과 배지함으로 확인할 수 있는 유아용 LXP 화면으로 재구성했다.

## 구현 위치

- `frontend/src/components/LxpSecretLandDashboard.tsx`
- `frontend/src/components/LxpSecretLandDashboard.css`
- `frontend/src/App.tsx`

## 데이터 연결

- 기존 `GameState.successCount`, `partyCount`, `roundId`만 사용한다.
- 성공 1회 이상과 성공 5회만 현재 카운터로 확인 가능한 배지 상태다.
- 재도전, 실패 후 성공, 콘텐츠 다양성, 발견 이벤트는 별도 이벤트가 없어 추론하지 않는다.
- 새 콘텐츠나 교육적 성취를 임의로 생성하지 않고 `기준 미정` 또는 `미지원`으로 표시한다.
- 기존 게임·API·DB 스키마와 놀이 화면 이동은 변경하지 않았다.

## 화면 구성

- 상단: 기능 미정 placeholder와 기존 배지함 진입
- 중앙: SVG 곡선 모험길, 1~5번 지점, 피키, 기존 기록 기반 진행 상태
- 하단: 다음 목표 미정 영역과 실제 카운터·배지 기억 영역
- 배지 도감은 기존 배지 목록을 재사용하되 실제 카운터로 확인할 수 없는 배지는 잠금 상태다.

## 검증

- `npm run build` 통과
- Vitest 10개 파일, 56개 테스트 통과
- Chrome 데스크톱 캡처에서 전체 영역과 모험길 확인
- 모바일 좁은 화면에서 설명 폭·지도 높이를 별도 조정

## 남은 문제

현재 프론트엔드 저장 기록에는 콘텐츠별 이벤트·재도전·발견 이력이 없으므로, 이를 실제 배지와 지점으로 확장하려면 기존 기록 API 또는 별도 이벤트 연결이 필요하다.
\n+## 2026-11-18 모험길 장면 및 연속 이동 보완

- 기존 5개 지점의 기록 조건은 유지하고, 화면 표현만 새싹 언덕·마법 샘·무지개 다리·구름 성·별빛 문으로 변경했습니다.
- `LivingPath`는 SVG viewBox 좌표와 `requestAnimationFrame` 보간으로 현재 기록이 허용하는 지점까지 피키를 곡선 경로를 따라 이동시킵니다. 기록이 없는 지점은 `다음 모험`으로 표시합니다.
- 장소별 배경은 외부 이미지가 아닌 컴포넌트 범위 CSS 도형으로 구성해 없는 에셋을 참조하지 않습니다.
- 활성 모험길에서는 중복된 `새 놀이 만나기` 이동 버튼을 렌더링하지 않습니다. 기존 메뉴·뒤로가기와 배지함 동작은 유지합니다.
- 모바일에서 부모 카드의 폭을 상속하도록 `play-card--secret-land`와 `lxp-secret`의 최소 폭을 정리해 지도와 상단·하단 카드가 뷰포트 밖으로 밀리지 않게 했습니다.

검증: `npm.cmd run build`, `npm.cmd run test -- --run`, `git diff --check` 통과. Chrome 캡처에서는 모험길 SVG, 장소별 장면, 피키 이동 레이어를 확인했으며, 모든 지정 해상도의 수동 동작 검증은 추가 확인이 필요합니다.
