# Before & After 관리 규칙

- 문서 목적: 화면·기능의 최초 기준과 검증된 최종 결과만 비교합니다.
- 관련 기능: 모든 UI/UX 변경
- 현재 상태: 관리 규칙 수립됨
- 마지막 확인일: 2026-11-12
- 관련 코드 위치: 화면별 React 컴포넌트와 CSS
- 관련 문서: [인트로 비교](intro.md) · [개발 현황](../DEVELOPMENT_STATUS.md)

## 저장 원칙

1. `screenshots/baseline/`에는 작업 시작 전의 최초 기준 이미지만 저장합니다.
2. `screenshots/final/`에는 기능·화면이 확정되고 실제 브라우저에서 검증된 결과만 저장합니다.
3. 여러 번의 중간 수정 캡처는 필수가 아닙니다. 중요한 기술 변화는 `features/` 문서에 기록합니다.
4. 최초 이미지나 최종 검증이 없으면 빈칸을 이미지로 채우지 않고 `자료 미확보` 또는 `개발 중`으로 표시합니다.

## 파일 이름

`화면명-해상도-YYYYMMDD.png` 형식을 권장합니다. 예: `intro-1366x768-20261112.png`.

## 새 비교 문서 양식

```md
# 화면명 Before & After

- BEFORE: 파일 또는 자료 미확보
- AFTER: 검증된 파일 또는 개발 중
- 확인일: YYYY-MM-DD
- 관련 기능: FEATURE-XXX

## 사용자가 느끼는 차이
## 핵심 변경
## 검증 결과
```
