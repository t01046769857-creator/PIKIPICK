# FEATURE-023 · 개인 맞춤형 LXP와 교사용 LMS 경로

## 구현한 경로

| 경로 | 현재 동작 |
| --- | --- |
| `/play` | 피키픽 아이용 첫 화면 |
| `/play/world` | 피키픽 비밀나라 |
| `/play/games` | 전체 놀이 선택 |
| `/teacher/login` | 교사용 로그인 준비 화면 |
| `/teacher/dashboard` | 담당 아동 연결 전 교사용 대시보드 구조 |
| `/teacher/children/:id` | 인증·담당 권한 전 접근 차단 안내 |

아이용 경로는 기존 게임 상태와 연결한다. 비밀나라에서 놀이 선택을 누르면 기존 전체 놀이 선택으로, 가위바위보를 누르면 기존 4개 모드 선택으로 이어진다.

## 교사용 보호 원칙

현재 역할 인증, 교사-아동 담당 관계, 동의 관리, 교사용 조회 API는 구현되어 있지 않다. 따라서 교사용 화면에는 실제 아동 이름·세션·이벤트·성취·도서 추천을 연결하지 않고 빈 상태만 표시한다. 개별 아동 URL은 실제 ID가 포함되어도 기록을 읽지 않고 권한 확인 필요 안내를 표시한다.

기존 세션 API는 세션별 Bearer 토큰을 요구하며, 이번 작업에서 새 교사용 데이터 API나 DB 마이그레이션은 추가하지 않았다. URL 분리만으로는 권한 보호가 완성되지 않으므로, 실제 연결 전에는 역할 기반 인증과 서버 측 담당 관계 검증이 필요하다.

## 도서 추천 상태

도서관 정보나루 API는 인증 승인 전으로 간주한다. 교사용 화면에는 실제 도서 검색 결과를 만들거나 호출하지 않으며, 교사 선택 기능과 API 승인이 준비된 뒤 연결할 영역으로만 표시한다.

## 후속 구현에 필요한 항목

1. 계정·역할·교사-아동 관계·동의 테이블과 재실행 가능한 마이그레이션
2. 로그인 세션 또는 안전한 토큰, 서버 측 `TEACHER` 권한 검사
3. 담당 관계를 검증하는 교사용 기록 조회 API
4. 세션·이벤트를 관찰 가능한 활동 지표로 변환하는 명시적 규칙
5. 승인된 도서 API를 교사 선택형 그림책 제안에 연결

이 항목들은 실제 개인정보와 아동 기록을 다루므로 이번 단계에서는 구현하지 않았다.
