# LXP 배지함 36개 이미지 복구 및 공통 크기

## 변경 목적

배지 도감의 36개 콘셉트 중 일부만 이미지가 연결되어 이름만 보이던 문제를 해결했다. 프로젝트에 저장된 개별 badge-art PNG와 기존 혼입 제거 clean PNG를 공통 이미지 레지스트리에서 연결했다.

## 구현

- badgeAssetByConceptId에 36개 도감 콘셉트의 이미지 경로를 등록했다.
- 런타임 획득 ID의 기존 매핑과 저장 데이터·획득 조건은 변경하지 않았다.
- 512×512 collection PNG는 76px 아트 박스 안에서 실제 알파 영역이 균일하게 보이도록 확대 보정했다.
- 기존 256×256 clean 드래곤 알·무지개 나비는 별도 스케일로 유지했다.
- 잠금 상태는 동일 이미지에 회색 필터를 적용하며, 이름·페이지 순서는 유지한다.

## 매핑 기준

수정 궁전, 드래곤 알, 무지개 나비, 반짝 보물상자는 이름과 그림이 확인된 매핑이다. 나머지는 저장된 asset_catalog의 주제와 가장 가까운 기존 PNG를 연결한 시각 후보이며, 이름과 완전히 일치하지 않는 후보는 후속 전용 일러스트 제작이 필요하다.

## 검증

- 36개 콘셉트 이미지 경로가 레지스트리에 존재하는지 TypeScript 테스트로 확인
- Vitest와 Vite build 실행 예정/결과는 작업 보고에 기록

## 남은 문제

현재 저장된 PNG 카탈로그에는 달빛 여우, 별빛 열쇠, 요정 우체통 등 일부 이름과 정확히 일치하는 그림이 없다. 해당 항목은 임시 후보 이미지를 사용하므로 최종 콘텐츠 확정 전 전용 PNG 재제작이 필요하다.
