# FEATURE-015 — 놀이 선택 카드의 승리 손 강조

- 날짜: 2026-11-13
- 목적: 5·6·7세 유아가 피키와 자신의 손, 놀이 목표를 그림으로 구별하도록 카드 내부만 변경한다.
- 변경 파일: `App.tsx`, `styles.css`, 신규 `components/ModeCardHands.tsx/css`, `components/ModeCardHands.test.tsx`.

## 카드 구성

왼쪽은 피키, 오른쪽은 아이로 고정한다. 기존 피키 이미지를 작게 표시하고 “피키”라는 짧은 이름을 붙인다. 아이 쪽은 작은 얼굴 표시와 “나”로 구분한다. 접근성 이름에도 좌우 역할과 손 이름을 포함한다.

| 카드 | 왼쪽 피키 | 오른쪽 아이 | 크게 표시하는 쪽 |
|---|---|---|---|
| 이기기 | 보 | 가위 | 아이 |
| 지기 | 가위 | 보 | 피키 |
| 비기기 | 가위 | 가위 | 없음, 동일 크기 |
| 규칙 연습 | 바위·가위·보 세 PNG | 역할 구분 없음 | 없음, 동일 크기 |

공식 PNG를 수정하거나 잘라내지 않고 공통 `PikiHand`로 표시한다. 승리한 손의 PNG 표시 크기는 상대의 1.30배다. 선택한 가위·보 PNG의 실제 가시 높이 기준 차이는 약 26%다. 손바닥·손가락 자체의 모양과 이미지 내부 여백은 보존한다. 연습 세 이미지도 같은 PNG 캔버스 크기를 사용하므로 주먹과 펼친 손의 원래 실루엣 차이는 유지된다.

기존 공통 손목 기준점에 맞춰 좌우 정렬한다. 역할 표시와 손가락이 겹치지 않도록 카드 내부 높이에 따라 손의 최대 크기를 제한한다. 승리한 쪽만 800ms 주기로 최대 2px 위로 움직이는 효과를 두 번 재생하고 종료한다. 추가 확대는 하지 않으며 reduced-motion에서는 효과를 끈다.

카드 배경은 이기기 살구, 지기 민트, 비기기 하늘, 규칙 연습 연분홍으로 구분한다. 테두리·둥근 형태·클릭 동작은 유지한다. 선택 화면의 전용 `ModeCardHands`가 예제 조합과 내부 표시만 담당하며 게임의 판정/진행 데이터로 사용되지 않는다.

## 영향 범위

기존 2×2 그리드와 카드 위치·크기를 유지했다. 상단 피키, 메뉴·뒤로가기·별 보상, 공식 PNG, 실제 게임 화면과 규칙 연습 화면의 손, 판정 함수·reducer·기록 로직은 변경하지 않았다. 앞선 인트로 말풍선 작업의 미커밋 변경을 보존했다. 파일 삭제·커밋·푸시는 실행하지 않았다.

## 검증

- `npm run build` 통과.
- `npm test`: 6개 파일·35개 테스트 통과. 새 테스트는 카드 예제를 기존 `isSuccessful`/`compareGestures`로 검증하고 좌우 역할, 공식 에셋 사용, 승리 손 개수와 연습의 세 동작을 확인한다.
- 실제 Chrome: 1440×900, 768×1024, 390×844, 320×740에서 Before 4장과 최종 After 4장을 확보했다.
- 모든 해상도에서 이기기·지기 승리 손 PNG 폭의 비율 1.300, 비기기 두 PNG 및 연습 세 PNG의 동일 폭을 확인했다.
- 카드 4개의 동일 크기, 각 손 이미지의 카드 경계 내 배치와 상호 비겹침, PNG 로딩, contain 비율 유지, 네 배경색 구분을 확인했다.
- 측정으로 카드 4개의 x/y/width/height와 로고·메뉴·별 영역의 좌표·크기가 수정 전과 동일함을 확인했다. 상단 피키의 기존 고개 기울이기 애니메이션은 순간 bounding box가 달라지므로 코드·스타일 불변과 화면으로 확인했다.
- 네 해상도에서 일반 게임 카드 12회 클릭 후 플레이 진입, 메뉴를 통한 놀이 선택 복귀, 연습 카드 4회 진입을 확인했다. reduced-motion에서도 강조 애니메이션이 꺼지는지 확인했다.
- `git diff --check` 통과. 게임 로직과 공식 손 PNG 경로에는 diff가 없다.

검증 캡처·측정 JSON·재현 스크립트는 [`screenshots/mode-card-winners/`](../screenshots/mode-card-winners/)에 있다. Before는 실제 수정 전 캡처이며, After는 검증한 최종 상태다. 실물 터치 기기의 조작감과 유아 대상 사용성 관찰은 미검증이다.
