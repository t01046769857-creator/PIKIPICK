# FEATURE-013 — 공식 손 파츠 공통 적용

- 날짜: 2026-11-12
- 목적: 완성된 독립 손 PNG를 공식 에셋으로 등록하고 모든 손동작 표시에서 같은 파일을 사용한다.
- 상태: 구현·빌드·테스트·브라우저 검증 완료.

## 에셋 확인과 등록

`hands/piki-hand-rock.png`, `piki-hand-scissors.png`, `piki-hand-paper.png`를 모두 직접 확인했다. 세 파일은 기존 제작본으로 준비되어 있었으며 가위의 흰색 질감·둥근 손가락·갈색 외곽선과 같은 계열이다. 미완성 대체 그림은 사용하지 않았고 이번 연결 단계에서 재생성하지 않았다. 각각 1024×1024 투명 PNG이며 공통 손목 기준점은 `(512,820)`이다. `hands/hand-spec.json`을 `registered-game-asset` 상태로 변경하고 가위를 스타일 기준으로 기록했다. 기존 마스터 및 전체 캐릭터 포즈는 변경하지 않았다.

`assetMap.ts`의 `pikiHands`가 `ROCK`, `SCISSORS`, `PAPER`를 각 PNG에 매핑한다. 기존 전체 캐릭터의 `pikiGestures`와 표정 매핑은 유지한다.

## 구현 및 화면 변화

- `PikiHand.tsx/css`: 공통 이미지 컴포넌트. 전체 PNG를 `object-fit: contain`, 정사각 비율로 표시한다. 손별 자르기·마스크·비율 변형이 없다. 공통 transform-origin은 손목 기준점에 해당하는 `50% 80.078125%`다. 장식용 이미지와 설명용 대체 텍스트를 구분한다.
- `App.tsx`, `styles.css`: 2×2 카드와 플레이 선택 버튼에 공통 손을 사용한다. 카드의 순서·크기·클릭 핸들러와 하단 선택 버튼의 동작은 유지한다. 손 내부 여백을 고려해 표시 크기를 지정한다.
- `GameRulePractice.tsx/css`: 원래 피키 캐릭터를 유지하고 같은 연습 `opponent`의 손 안내를 옆에 표시한다. 선택 버튼도 세 공식 PNG로 교체한다. 기존 예제·정답 판정·이전/다음·완료·건너뛰기는 유지한다.
- `PikiOpponent.tsx/css`: 모든 게임의 PLAYING/RESULT 강조 손을 공통 컴포넌트로 표시한다. App에서 전달한 실제 `state.opponent`를 그대로 사용한다. 성공/재도전 표정과 파티 클래스, 기존 0.25초 전환, reduced-motion 처리를 유지한다. PNG의 투명 여백을 고려해 강조 손 영역만 조정한다.
- `StoryNavigation.tsx/css`: 놀이 선택·규칙 연습 메뉴에 남아 있던 손 SVG를 같은 PNG로 교체한다. 메뉴의 위치·카드·이동·소리 기능과 다른 아이콘은 유지한다.
- `PikiOriginalHand.tsx`: 임의 clipPath 구현을 제거한다. `PikiOpponent` 내부의 임시 SVG 손과 손동작 이모지도 제거했다.

변경하지 않은 영역: 게임 규칙·승패 판정·reducer·기록 저장·별 계산, 기존 캐릭터 원본과 애니메이션, 배경, 메뉴/뒤로가기 동작. 새로운 리깅 시스템은 추가하지 않았다.

## 검증

- `npm run build` 통과.
- `npm test`: 5개 파일, 31개 테스트 통과. 공통 PNG 매핑, 모든 모드·상대·사용자 손 조합의 결과 표시, 표정/파티 클래스 보존, 연습 안내·세 선택지의 공통 에셋 사용을 검사한다. 기존 규칙·기록·네비게이션 테스트도 통과했다.
- Chrome headless 실제 브라우저: 1440×900, 768×1024, 390×844, 320×740.
- 4개 해상도에서 동일 크기의 2×2 카드 확인, 총 36개 연습 예제의 안내 손·캐릭터 손 일치와 정답 피드백 확인, 연습 중 기록 불변 확인.
- 세 모드 × 네 해상도, 12회 게임 시작에서 실제 피키 이미지와 강조 PNG의 Gesture 일치 확인. 결과 4회에서도 직전 출제 손 유지 확인.
- 모든 검사 화면에서 공식 PNG 로딩과 1024px 원본 크기, `object-fit: contain` 확인. 손 윤곽이 잘리거나 늘어나지 않는 것을 주요 스크린샷에서 직접 확인.
- 카드의 동일 너비·높이와 배치 순서, 화면 너비 안 배치 확인. 플레이의 상대 영역 하단과 선택 영역 상단 사이가 양수이며 가로 넘침이 없음.
- 연습 완료·건너뛰기, 메뉴의 놀이 선택·규칙 연습·내 별, 뒤로가기 동작을 확인.
- 프로덕션 소스에 임시 `PikiOriginalHand`, 손 SVG 클래스, `clipPath`, `<mask`, 가위바위보 이모지가 남지 않은 것을 검색 확인.
- 기존 마스터·게임용 원본 3개 SHA-256을 제작 시 기록과 비교해 동일함을 확인.

최종 캡처 24개와 측정 데이터는 [`screenshots/hand-assets/`](../screenshots/hand-assets/)에 있다. 브라우저 측정은 [`browser-check.json`](../screenshots/hand-assets/browser-check.json)에 기록했다. 별도 프로필을 사용해 사용자의 실제 저장 기록을 변경하지 않았다. 이번 작업의 Before 화면 캡처는 없으며, 캡처는 최종 상태 검증 자료다.

미검증: 실제 터치 기기의 터치감·고밀도 화면, 지정한 해상도 외 모든 크기. 매우 짧은 화면과 모바일 연습 화면은 페이지 스크롤을 사용할 수 있다.
