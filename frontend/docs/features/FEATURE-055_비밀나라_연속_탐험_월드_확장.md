# FEATURE-055 비밀나라 2D 연속 탐험 월드 확장

## 목적

기존 2400×800 비밀나라를 9000×900 공통 월드 좌표로 확장하고, 기존 피키 이동·접지·카메라·해금 상태를 유지하면서 다리와 양쪽 지형을 하나의 횡스크롤 세계로 연결한다.

## 디자인 팩 검수

`PIKIPICK_secretland_world_design_pack.zip`의 33개 파일과 프로젝트에 보관된 `frontend/src/assets/secret-land/world-design/`를 대조했다.

- `00_overview`, `01_zone_references`, `03_common_path_reference`는 불투명한 콘셉트/참고 이미지다. 런타임 배경이나 투명 오버레이로 사용하지 않는다.
- `02_landmark_candidates`에서 새싹 언덕, 마법 샘, 구름 지역, 별빛 지역의 4개 PNG만 투명 랜드마크 후보로 사용한다.
- `03_rainbow_bridge_VISUAL_REFERENCE_ONLY.png`는 참고용으로 유지하고 런타임 다리로 사용하지 않는다.
- 승인된 `world-terrain-compact-rainbow-bridge-v3-2400x800.png`를 그대로 중앙 구간에 배치한다.

## 월드와 목적지 좌표

| ID | 이름 | landmark | pathAnchor | routeNode |
| --- | --- | --- | --- | --- |
| `sprout` | 새싹 언덕 | (600, 500) | (600, 680) | 1 |
| `spring` | 마법 샘 | (2450, 440) | (2450, 610) | 7 |
| `bridge` | 무지개 다리 | (4400, 315) | (4400, 410) | 14 |
| `castle` | 구름 성 | (6400, 430) | (6300, 610) | 20 |
| `gate` | 별빛 문 | (8000, 405) | (7900, 590) | 25 |

`landmark`는 그래픽 중심, `pathAnchor`는 피키 발이 닿는 경로 기준점이다. 기존 장면 ID와 해금 순서는 변경하지 않았다.

## 경로 길이

피키의 기존 `ADVENTURE_WALK_SPEED = 100`과 현재 Catmull-Rom 샘플링 함수로 목적지 사이의 실제 곡선 길이를 계산했다.

| 구간 | 경로 길이 | 100px/s 예상 시간 |
| --- | ---: | ---: |
| 새싹 언덕 → 마법 샘 | 약 1862px | 약 18.6초 |
| 마법 샘 → 무지개 다리 | 약 1989px | 약 19.9초 |
| 무지개 다리 → 구름 성 | 약 1944px | 약 19.4초 |
| 구름 성 → 별빛 문 | 약 1911px | 약 19.1초 |

전체 경로는 약 7706px이며, 월드 끝의 여백을 포함해 9000×900으로 유지한다.

## 배경 연결 방식

승인된 다리 배경은 월드 `(3100, 50)`에 `2400×800` 원본 크기로 배치한다. 기존 다리의 강물·데크·양쪽 연결부는 이 이미지가 담당한다. 다리 왼쪽은 route node 0–11, 다리 구간은 node 11–19, 오른쪽은 node 19–26으로 분리해 디버그 표시와 경로 검증이 가능하도록 했다.

다리 바깥의 기본 지형은 공통 월드 레이어의 연속 색상 지형과 경로 스트로크로 연결했다. 이는 현재 팩에 투명한 제작용 연결 지형·강물·꽃밭 에셋이 없기 때문에 적용한 구조용 단계다. 참고 보드를 잘라 붙이거나 다리 이미지를 반복 복제하지 않았다.

## 기존 기능 보호

- `adventurePosition`, Catmull-Rom 보간, 100px/s 이동, 방향별 walk-v2 프레임, footAnchor, 카메라 계산은 재사용한다.
- 클릭 이동, 방향키 이동, 잠긴 경계, 해금 상태, 재입장 저장 키는 변경하지 않는다.
- 배지·보물상자·API·DB·LMS는 변경하지 않는다.
- 기존 2400×800 월드 이미지는 덮어쓰지 않는다.

## 검증 결과

- `npm.cmd run build`: 통과
- `npm.cmd test -- --run`: 12개 파일, 63개 테스트 통과
- `localhost:5173/play/world` 렌더링: 1440×900, 1024×768, 390×844에서 새 월드/지형 레이어, 승인 다리 구간, 4개 랜드마크가 DOM에 표시됨.
- 확인된 렌더링 값: 월드 레이어 9000×900 비율, 승인 다리 세그먼트 2400×800 비율, 랜드마크 4개, 공통 경로 SVG 1개.
- 임시 헤드리스 브라우저에서는 키보드 이벤트 포커스 전달이 되지 않아 실제 방향키 이동 동작은 별도 대화형 브라우저에서 재검증이 필요하다.

## 남은 작업

현재 디자인 팩에는 연결 지형을 바로 사용할 수 있는 투명 제작 에셋이 없다. 최종 시각 품질을 높이려면 9000×900 동일 좌표계의 투명 지형/강물/꽃밭/바위 세트를 별도로 제작하고, 실제 브라우저에서 다리 양끝과 피키 발 접지를 다시 확인해야 한다.
