## 기준 리소스

피키의 외형 기준은 `src/assets/characters/piki/references/PIKI_MASTER_A.png` 하나로 고정한다. 콘셉트 시트와 표정·포즈 시트는 표현을 확장하기 위한 참고 자료이며, 다른 시안의 캐릭터 외형을 섞지 않는다.

## 고정 디자인 규칙

- 하얗고 둥근 말랑콩형 머리와 작은 몸을 유지한다.
- 머리 양옆에는 부드럽고 둥근 귀 모양이 있다.
- 머리 위에는 분홍색 두 봉우리 돌기가 있다.
- 양 볼에는 분홍색 볼터치를 둔다.
- 모든 외곽에는 짙은 갈색에 가까운 굵은 선을 사용한다.
- 목에는 민트색 삼각 목 장식을 두고, 중앙에 노란 별을 넣는다.
- 표정과 자세가 바뀌어도 머리·귀·돌기·목 장식의 비율과 색은 바꾸지 않는다.

## 성격과 연출

피키는 깨발랄하고 장난스럽지만 아이를 안심시키고 다시 시도하게 돕는 친구다. 성공할 때는 함께 신나고, 실수할 때는 부담 없이 응원한다. 손동작을 안내할 때는 한 번에 하나의 동작만 선명하게 보여 준다.

## 에셋 규칙

- `references/`: 원본 마스터와 참고 시트만 보관한다.
- `expressions/`: 장면별 표정·자세 PNG를 보관한다.
- `gestures/`: 바위·가위·보 손동작 PNG를 보관한다.
- 개별 PNG는 투명 배경, 단일 피키, 충분한 여백을 기본으로 한다.
- 화면에서는 `assetMap.ts`를 통해서만 에셋을 선택한다.

## 표정 구분 규칙

`><` 형태의 눈은 크게 웃거나 장난칠 때만 제한적으로 사용한다. 기본 표정과 응원에 반복하지 않는다.

| 에셋 | 눈·입 | 자세와 실루엣 |
| --- | --- | --- |
| `basicGreeting` | 반짝이는 동그란 눈, 활짝 웃는 입 | 고개를 살짝 기울이고 한 손으로 인사 |
| `successHappy` | 반달눈, 크게 웃는 입 | 양손을 높이 들고 폴짝 뜀 |
| `curious` | 옆을 보는 타원 눈, 오므린 O 입 | 턱을 짚고 한쪽 귀를 낮춤 |
| `surprised` | 크게 뜬 눈, 작은 O 입, 치켜뜬 눈썹 | 양 볼에 손을 대고 귀를 활짝 폄 |
| `playful` | 한쪽 윙크와 별 반짝임 눈, 혀를 내민 입 | 몸을 비스듬히 기울이고 장난스러운 손짓 |
| `encourage` | 따뜻한 큰 눈, 다정한 미소 | 한 손을 내밀고 다른 손은 목 장식의 별에 댐 |

전체 비교는 `src/assets/characters/piki/previews/piki-expression-preview-sheet.png`에서 확인한다. 시트는 개별 PNG를 그대로 배열한 미리보기이며, 왼쪽 위부터 표의 순서대로 배치된다.

## 시작 장면 프레임

원본 PNG는 완성된 단일 일러스트라 팔·입을 안전하게 분리해 리깅할 수 없다. 따라서 시작 장면은 아래의 A안 기반 전용 프레임과 CSS 탄성 애니메이션을 조합한다.

- `expressions/piki-intro-reach.png`: 화면 앞으로 손을 내밀고 반대 손을 흔드는 초대 자세
- `expressions/piki-intro-talk.png`: 말하는 입 모양의 초대 자세

`PikiIntroScene`은 `peek → approach → reach → talk → invite` 상태로 프레임을 바꾸며, 말하는 동안에는 말하기 프레임과 부드러운 몸·분홍 돌기 흔들림을 사용한다. 새 캐릭터나 별도 캐릭터 시안은 사용하지 않는다.
