# 비밀나라 고품질 랜드마크 검수 기록

검수일: 2026-11-20

## 검수 범위

기존 런타임과 9000×900 월드 좌표를 유지한 상태에서 `place-*` 랜드마크 5종을 실제 PNG로 열어 확인하고, 무지개 다리 PNG를 별도 오버레이로 시험했다. 승인되지 않은 원본 이미지와 이동·발 접지·카메라 로직은 수정하지 않았다.

## PNG 측정

`alpha bounds`는 A>0인 픽셀의 외곽, `strong bounds`는 A>=240인 픽셀의 외곽이다. `base y`는 strong bounds의 최하단 y로, 투명 여백을 제외한 시각적 바닥 후보이다.

| 파일 | 원본 크기 | alpha bounds | strong bounds | 강한 불투명 영역 비율 | base 후보 (x,y) |
| --- | ---: | --- | --- | ---: | ---: |
| `place-sprout-hill-v2.png` | 1536×1024 | 0,23–1535,1023 | 50,83–1483,958 | 47.8% | (766.5, 958) |
| `place-magic-spring-v2.png` | 1536×1024 | 0,0–1515,1023 | 38,18–1502,1001 | 59.9% | (770, 1001) |
| `place-rainbow-bridge-v2.png` | 1752×897 | 0,0–1751,896 | 12,12–1743,886 | 66.5% | (877.5, 886) |
| `place-cloud-castle-v2.png` | 1536×1024 | 0,0–1535,1023 | 64,11–1471,1012 | 47.4% | (767.5, 1012) |
| `place-starlight-gate-v2.png` | 1536×1024 | 0,0–1535,1023 | 109,8–1430,1014 | 52.4% | (769.5, 1014) |

다섯 PNG 모두 알파 채널을 가진 독립 일러스트이며, 원본 파일은 변경하지 않았다. 실제 내용은 각각 언덕·샘·무지개 다리·구름 성·별빛 문으로 확인된다. 위 base 후보의 x는 강한 불투명 바운딩 박스의 중앙값이며, 풀·물·그림자까지 포함한 시각적 하단 기준이지 피키의 보행 발 기준점은 아니다.

## 현재 런타임 연결

`secretLandAssets.destinations`에는 5종이 모두 매핑되어 있다. `WorldTerrainLayer`는 현재 다리 구간을 별도 SVG 보행 구조로 유지하기 때문에 `bridge`를 제외한 4종(`sprout`, `spring`, `castle`, `gate`)을 투명 PNG 랜드마크로 렌더링한다. 다리 PNG import는 존재하지만 현재 화면에는 사용하지 않는다.

## 무지개 다리 PNG 대체 검수

현재 랜드마크 sceneBounds(460×260)에 `place-rainbow-bridge-v2.png`를 별도 주입하고, 기존 27개 경로의 다리 구간(`adventureRoutePath(9, 19)`)을 위에 표시했다.

결과는 **통과하지 못함**이다.

- 이미지의 무지개 상판·좌우 진입 계단은 고품질이지만 현재 경로는 이미지의 상판이 아니라 이미지 앞쪽 SVG 흙길에 놓인다.
- PNG를 2400×800 다리 배경처럼 확대하면 원본 비율(1752×897)이 월드 다리 영역과 맞지 않아 주변 강물·강둑이 왜곡되거나 가려진다.
- 현재 경로·footAnchor·27개 노드를 바꾸지 않고는 피키가 PNG 상판을 걷는 화면을 만들 수 없다.

따라서 이번 검수에서는 SVG 다리를 제거하거나 PNG를 런타임에 추가하지 않았다.

## 첫 구역 판정

새싹 언덕과 마법 샘의 고품질 PNG 자체는 현재 화면에 표시되지만, SVG 흙길과 랜드마크 내부 돌길 사이에 시각적 단절이 남는다. 고품질 2.5D 지형으로 완료 처리하려면 투명 흙길·잔디 가장자리·강둑/물가·다리 데크 연결 에셋이 추가로 필요하다. 기존 `world-design/03_common_path_reference` 자료는 불투명 참고 이미지라 그대로 런타임 장식으로 사용하지 않았다.

## 검증 결과

- Build: 통과 (`npm.cmd run build`)
- Vitest: 통과 (12개 파일, 63개 테스트)
- 브라우저: 1440×900, 1024×768, 390×844 캡처 완료
- 세 화면 모두 수평 overflow 없음; 랜드마크 4개 렌더링 확인
- 클릭/키보드 이동 및 기존 position 저장 복원 확인
- 다리 PNG 대체는 위 사유로 보류
