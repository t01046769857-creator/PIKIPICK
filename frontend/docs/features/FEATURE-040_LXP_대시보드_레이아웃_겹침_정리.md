# FEATURE-040 — LXP 대시보드 레이아웃 및 겹침 정리

## 변경 목적

아이용 비밀나라 대시보드를 `상단 2열 → 중앙 모험 지도 → 하단 2열`의 고정된 화면 구조로 정리하고, 지도 안의 피키·경로·목적지·라벨이 서로 가리지 않도록 배치 책임을 분리했다.

## 수정 파일

- `frontend/src/components/LxpSecretLandDashboard.tsx`
- `frontend/src/components/LxpSecretLandDashboard.css`

## 구현 내용

- 상단은 `TreasureDisplay`와 `MagicBadgeBook`을 동일한 그리드 행에 배치한다.
- 중앙 지도는 긴 월드 좌표계와 viewport를 사용하며, 배경(`LongWorldDecor`), 경로 SVG, 목적지 목록, 피키 이동 레이어를 분리한다.
- 목적지 라벨은 경로 위치에 따라 위·아래 안전 영역을 번갈아 사용해 피키의 이동 영역과 분리한다.
- 피키는 길 중심선 위에 두되 라벨을 가리지 않도록 시각적 기준점을 보정하고, 피키 이름을 별도 텍스트로 중복 표시하지 않는다.
- 하단은 다음 목표 카드와 놀이 경험 카드의 2열 구조를 유지한다. 배지 아이콘은 놀이 경험 카드에서 중복 표시하지 않는다.
- 긴 월드의 카메라는 피키 위치를 따라가며 일반 페이지 세로 스크롤을 늘리지 않는다.

## 데이터 및 기능 영향

기존 `successCount`, `partyCount`, `roundCount`, 배지 데이터, `onBadges`, `onPlay` 및 기존 기록 판정 로직을 그대로 사용한다. API, DB, 게임 규칙, LMS는 변경하지 않았다.

## 검증

- `npm.cmd run build`: 통과
- Vitest: 11개 파일, 57개 테스트 통과
- `git diff --check`: 통과
- 실제 브라우저 1440×900 캡처: 상단 2열·중앙 지도·하단 2열 및 기본 피키 표시 확인
- 실제 브라우저 모바일 캡처: 좁은 viewport에서 상단·하단이 1열로 재배치되고 지도 내부 요소가 표시되는 것을 확인했다. 브라우저 캡처 도구의 viewport 보정으로 정확한 390 CSS px bounding-rectangle 측정은 미실행이다.

## 남은 확인 사항

클릭 이동·더블클릭 점프의 실제 입력 검증과 390×844, 768×1024, 1024×768 환경의 브라우저 캡처는 별도 수동 확인이 필요하다. 현재 지도 풍경은 프로젝트 내 별도 고품질 raster 에셋 없이 기존 구조의 SVG 장식으로 구성되어 있다.
