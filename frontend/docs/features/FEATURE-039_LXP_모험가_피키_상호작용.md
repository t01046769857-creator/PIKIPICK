# FEATURE-039 · 모험가 피키 상호작용

- 지도 viewport 클릭·터치 시 현재 해금된 목적지 중 가장 가까운 지점으로 피키가 이동한다.
- 이동은 긴 SVG 곡선 월드와 카메라 추적 레이어를 그대로 사용한다.
- 더블클릭·더블탭은 목적지 이동 대신 피키의 제자리 콩콩 점프를 실행한다.
- 피키 원본 이미지는 유지하고 CSS 오버레이로 작은 탐험 모자와 배낭을 추가했다.
- 도착 시 해당 장소에 짧은 반짝임과 glow를 표시하며, 해금 축하 메시지는 새 해금 때만 표시한다.
- 잠긴 목적지, 기록, API, DB, LMS는 변경하지 않았다.
- 제공된 `piki-explorer-run-left-source.png`와 `piki-explorer-run-right-source.png`를 이동 중 방향별 이미지로 적용했다. 정지 상태는 기존 `piki-explorer-adventurer.png`를 유지하며, 참고용 RGB 모션 시트는 체커보드·라벨이 포함되어 있어 게임 프레임으로 분리하지 않았다.
- 좌우 소스는 각각 1254×1254 RGBA로 확인했고, 가장 큰 캐릭터 알파 컴포넌트의 부츠 최하단을 기준으로 방향별 `footAnchor`를 정의했다. 이동 중 기존 수직 translate 바운스를 제거해 발 접지 기준이 흔들리지 않도록 했다.

검증: `npm.cmd run build`, Vitest 58개, Chrome DevTools 실제 화면에서 우측 이동 시 `run-right-source`, 좌측 이동 시 `run-left-source`, 정지 시 기존 원본 선택을 확인했다. 390×844에서 수평 스크롤이 없음을 확인했다. 점프 전용 개별 PNG와 다중 걷기 프레임은 제공되지 않아 기존 점프 연출과 단일 방향 소스만 적용했다.

## 2026-11-19 · 정지 에셋 교체

- 정지 상태를 `piki-explorer-idle-front.png`로 교체했다. 기존 `piki-explorer-adventurer.png`는 정지 상태 import에서 제거했으며 파일 자체는 보존한다.
- 정지 PNG는 1312×1199, 8-bit RGBA로 확인했고 두 발로 선 정면 자세와 투명 배경을 확인했다.
- 정지 전용 접지점은 두 부츠 접촉 영역의 중앙 및 최하단 불투명 픽셀을 기준으로 `footAnchor = { x: 668 / 1312, y: 1191 / 1199 }`로 설정했다. 표시 폭은 116px로 조정했다.
- 좌우 이동 에셋, 입력 로직, 월드 경로, 카메라, 점프 동작은 변경하지 않았다.

검증: Vitest 59개 및 `npm.cmd run build` 통과. 실제 브라우저에서 정지 전환과 무지개 다리 접지 화면을 캡처하는 검증은 현재 브라우저 자동화 환경 부재로 미실행.

## 2026-11-19 재입장 위치 및 해금 경계 보완

- 활성 `LivingPath`는 현재 놀이 기록으로 계산된 해금 지점과 기존 `pikipick.secret-land.unlock.v1` 저장값 중 가장 마지막 지점을 재입장 기준으로 사용한다. 컴포넌트가 다시 마운트되면 해당 지점의 `pathAnchor`에서 시작하며 이동·점프·카메라 상태는 새로 초기화된다.
- 저장값은 해금 상태를 대체하지 않고 기존 해금 진행을 보존하는 보조 기준으로만 사용한다. 현재 프로젝트에 정의된 조건(첫 놀이 기록 → 새싹 언덕, 성공 1회 이상 → 마법 샘, 성공 5회 이상 → 무지개 다리)은 변경하지 않았다.
- 클릭·터치와 방향키 `ArrowLeft`/`ArrowRight`는 같은 `desiredStop`과 `adventurePosition` 경로를 사용한다. 이동 방향은 월드 x 변화로 판정하므로 두 입력 모두 동일한 좌우 피키 에셋을 선택한다.
- 해금되지 않은 지점을 클릭하거나 오른쪽 방향키로 요청하면 현재 위치를 변경하지 않고 잠금 안내를 표시한다. 안내를 닫아도 현재 위치와 카메라가 유지되며, 뒤쪽 해금 지점으로 이동하는 입력에는 잠금 안내를 표시하지 않는다.
