# FEATURE-011 — 플레이 캐릭터와 손동작 시인성

- 변경일: 2026-11-12
- 목적: 모든 실제 게임 모드에서 캐릭터와 출제 손동작을 크게 보여 준다.
- 파일: `components/PikiOpponent.tsx/css`, `components/PikiOpponent.test.tsx`, `App.tsx`, `styles.css`.

## 구현과 화면 변화

이기기·지기·비기기의 공통 PLAYING/RESULT 영역을 `PikiOpponent`로 묶었다. 기존 `PikiCharacter`의 이미지와 성공/재도전 표정 및 파티 애니메이션을 그대로 재사용한다. 전역 캐릭터 컴포넌트를 확대하지 않고 플레이 영역의 기존 크기 규칙만 1.4배로 변경했다.

- 기본: `clamp(210px, 34vh, 320px)` → `clamp(294px, 47.6vh, 448px)`.
- 모바일: `clamp(155px, 29vh, 220px)` → `clamp(217px, 40.6vh, 308px)`.
- 낮은 모바일: `min(27vh, 185px)` → `min(37.8vh, 259px)`.

가용 너비보다 커지는 경우에는 너비를 제한하고 정사각형 비율을 유지한다. 큰 화면은 캐릭터 옆에 100~160px의 독립 SVG 손 파츠를 표시하고 520px 이하에서는 캐릭터 아래에 80~110px로 표시한다. 기존 피키 손과 같은 흰색 면과 둥근 갈색 선의 주먹·가위·보를 사용한다. 원본 PNG와 캐릭터 디자인을 수정하지 않는다.

캐릭터와 강조 손 모두 `state.opponent`를 사용한다. 손 이름도 같은 값에서 가져온다. 결과 화면에서는 기존 성공/재도전 표정을 유지하면서 해당 문제의 상대 손을 계속 보여 준다. 손이 바뀌면 0.25초의 투명도·위치·크기 전환으로 나타나며 reduced-motion 설정에서는 이 전환을 끈다.

## 영향 범위와 보존

게임 선택·규칙 연습·인트로의 캐릭터 크기는 변경하지 않는다. 현재 저장소의 실제 플레이 모드는 모두 동일한 공통 플레이 영역을 사용한다. 전용 CSS는 `.app-shell--game` 범위로 제한한다. 공통 CSS의 기존 활성 크기 규칙 세 곳을 수정해 충돌하는 크기 덮어쓰기를 추가하지 않았다. 하단 선택 버튼의 마크업·스타일, 메뉴, 배경, 판정과 보상·저장 로직은 변경하지 않는다.

확대 영역과 강조 손은 문서 흐름에 포함되고 카드의 기존 자동 높이를 사용한다. 결과 피드백과 선택 버튼은 그 다음 행에 배치되어 확대 요소와 겹치지 않는다. 세로 공간이 매우 짧으면 페이지 스크롤이 필요할 수 있다.

## 검증과 남은 확인

`npm run build` 통과. `npm test` 4개 파일·24개 테스트 통과. 공통 컴포넌트 렌더 테스트에서 세 출제 손의 이미지와 강조 손 이름 일치, 성공/재도전 시 기존 표정과 출제 손 유지, 파티 클래스 유지를 확인했다. 기존 판정·보상·기록·네비게이션 테스트도 통과했다.

수정 전후 브라우저 캡처는 확보하지 못했다. 실제 모바일·태블릿·PC에서 확대 비율, 손 그림 식별성, 결과 피드백과 선택 버튼 간격 및 짧은 가로 화면의 스크롤은 브라우저 확인이 남아 있다.
