# FEATURE-037 · LXP 긴 모험길과 카메라 추적

## 구현

- `LxpSecretLandDashboard.tsx`에 2400 단위의 긴 월드 좌표계를 추가했다.
- 다섯 목적지는 기존 기록 조건과 순서를 유지하면서 긴 곡선 SVG 경로에 배치했다.
- 지도 내부 viewport 안에서만 월드 레이어를 `translate3d`로 이동시켜 일반 페이지 스크롤과 분리했다.
- 피키 위치에서 viewport 중심을 계산해 카메라가 따라가도록 했다.
- 월드에는 언덕·나무·꽃·물길·돌길을 별도 SVG 전경 레이어로 배치했다.
- 움직임 감소 설정이 있으면 전역 reduced-motion 규칙에 따라 이동 애니메이션을 생략한다.

## 보존 및 한계

해금 조건·localStorage 기준점·배지·기록·API·LMS는 유지했다. 장소 전용 고품질 래스터 에셋은 저장소에 없어 현재는 인라인 SVG로 구성했다. 실제 기록을 임의 주입하지 않았으므로 해금 증가와 장거리 이동을 자동 브라우저 시나리오로 재생한 검증은 별도 필요하다.

## 검증

`npm.cmd run build`, Vitest 57개, `git diff --check` 통과. Chrome 1440×900 및 390×844에서 월드 viewport와 카메라 시작 화면을 확인했다.
