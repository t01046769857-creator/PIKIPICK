# 인트로 화면 Before & After

- 문서 목적: 피키 인트로 화면의 최초 기준과 검증된 최종 상태를 비교합니다.
- 관련 기능: 피키 등장, 말풍선, 손 터치 시작
- 현재 상태: 개발 중 — 최종 확정 전
- 마지막 확인일: 2026-11-12
- 관련 코드 위치: [`../../src/components/PikiIntroScene.tsx`](../../src/components/PikiIntroScene.tsx), [`../../src/styles.css`](../../src/styles.css)
- 관련 문서: [FEATURE-001](../features/FEATURE-001_피키_손_터치_놀이_시작.md)

## BEFORE

최초 화면 캡처는 Git 이력과 `screenshots/baseline/`에서 확인되지 않았습니다. **최초 자료 미확보**입니다.

## AFTER

**개발 중 — 최종 확정 전**입니다. 인트로는 현재 작업 폴더에서 반응형 레이아웃, 배경, 등장 좌표가 계속 수정되고 있으므로 최종 스크린샷을 저장하지 않습니다.

## 코드로 확인되는 현재 목표

- 피키가 화면 옆에서 PEEK 단계로 나타납니다.
- 손을 내민 뒤 `나랑 같이 놀자!` 말풍선을 보여 줍니다.
- 보는 사람 기준 왼쪽의 큰 손을 누르면 `BEGIN`을 통해 놀이 선택으로 갑니다.

실제 화면이 이 목표와 일치하는지는 브라우저 검증 후에만 최종 비교에 기록합니다.
