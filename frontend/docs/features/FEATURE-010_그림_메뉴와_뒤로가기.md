## 화면과 구현

공통 SVG 아이콘은 파스텔 면, 둥근 형태, 5 단위의 갈색 외곽선을 사용한다. 그림 메뉴 버튼 하나에서 집(처음으로), 세 손(놀이 선택), 손 따라하기(규칙 연습), 별 주머니(내 별), 스피커(소리)의 큰 그림 카드를 연다. 각 카드는 짧은 이름과 접근성 이름을 제공한다. 네이티브 dialog로 메뉴의 키보드 포커스를 제한하고 Escape·닫기 버튼·바깥 클릭으로 닫는다.

첫 화면의 소리 텍스트 버튼을 같은 메뉴로 교체한다. 피키, 배경과 인트로 애니메이션은 유지한다. 소리는 App의 공통 상태로 관리해 음소거 시 인트로 발화를 취소하고 게임 리듬·파티 효과음의 AudioContext를 정리한다. 다시 켜면 기존 효과음 함수를 사용한다. 브라우저의 오디오 재생 제한은 기존처럼 적용된다.

첫 화면을 제외한 화면의 카드 좌측 상단에 큰 뒤로 화살표를 배치한다. 게임 카드 크기와 콘텐츠 흐름을 밀지 않도록 위치만 겹쳐 배치한다. App은 명시적 화면 이동 때 화면·모드·상대 손·결과만 스택에 저장한다. 뒤로 가기는 최근 화면을 복원하되 별·누적 기록과 문제 번호를 과거 값으로 돌리지 않는다. 게임 화면을 벗어나면 기존 effect 정리로 진행 타이머와 효과음이 중단된다. 결과 화면을 복원하면 기존 자동 진행이 재개된다. 연습 화면은 다시 마운트되면 첫 예제부터 시작한다.

규칙 연습의 이전·다음·건너뛰기도 공통 그림 아이콘을 사용한다. 연습 완료·건너뛰기 후 게임 선택으로 돌아가는 동작은 유지한다. 메뉴를 통해서는 어느 화면에서든 연습에 직접 진입할 수 있다.

“내 별”은 현재 누적 성공 수(모은 별)와 파티 횟수를 표시한다. 기존 기록 초기화 확인 기능은 이 화면의 “기록 설정”에서 접근한다. 초기화의 기존 확인 절차와 reducer 로직을 유지한다.

## 영향과 보존

승패 판정 함수, 별 계산·저장 로직, 캐릭터 이미지·애니메이션, 배경, 게임 선택 카드와 실제 게임 선택 버튼은 변경하지 않는다. 메뉴 전용 CSS와 기존 연습 버튼 CSS만 변경하며 이전 작업의 공통 CSS 변경은 보존한다. 새로운 RECORDS는 화면 단계이며 게임 모드가 아니다.
