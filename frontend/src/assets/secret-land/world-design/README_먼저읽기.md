# PIKIPICK Secret Land — 전체 시안 + 개별 참고 이미지 + 좌표 설계 자료

## 구분
1. `00_overview/`: 전체 월드 시안과 상단 연결길 참고 이미지. 그대로 게임 월드 배경으로 사용하면 안 됨.
2. `01_zone_references/`: 구역별 콘셉트 카드와 풍경 크롭. **RGB/불투명 참고 이미지**로 직접 PNG 레이어로 적용하지 말 것.
3. `02_landmark_candidates/`: 기존에 별도로 생성된 **개별 RGBA 일러스트**. 독립 오브젝트 후보(광장/샘/구름/문). 이미지의 보행 경로와 크기가 실제 2D 월드와 맞는지 검수 필요. 무지개 다리 파일은 기존 승인 원본 교체용이 아닌 참고용.
4. `03_common_path_reference/`: 흙길·표지판·울타리·꽃·돌·버섯 등 원본 시안에서 분리한 **불투명 그림 참고 크롭**. 잘린 조각을 투명 에셋처럼 바로 합성하지 마세요. 필요하면 승인된 그림체로 개별 투명 에셋을 별도 제작.
5. `04_layout_and_coordinates/`: 긴 월드 구상도, 제안 좌표 스펙, 전체 파일 목록. 9000×900은 **디자인 예시 좌표**이고 실제 앱 좌표가 아닙니다.

## 확정된 요구사항
- 5개 목적지, 하나의 긴 2D 월드, 구간당 목표 15~20초 이동, 장소 사이 꽃/새싹/나비/표지판 등의 발견 요소.
- 해금된 구간 자유 이동·되돌아가기, 이동을 멈춘 위치 유지, 재입장 시 마지막 해금 장소.
- 기존 승인 무지개 다리 보존. 새 그림 하나를 기존 월드 위에 대충 얹는 방식 금지.

## 반드시 확인할 것
- 실제 프로젝트의 5개 지명/순서는 소스 데이터로 먼저 확인할 것. 여기에서 4·5번으로 표시된 `구름 정원`, `별빛 궁전`은 **시안 임시명**, 기존 게임 이름을 대체하지 않음.
- 임의의 destination coordinates, route geometry, unlock data, browser storage를 변경하지 말 것.
- 그림과 피키의 발 좌표가 맞는지, 길 연결이 자연스러운지, 15~20초 걷기에 충분한지 **실제 브라우저**에서 확인 후 단계적 적용.
- 이 ZIP은 아트 디렉션/좌표 설계 전달물이지, 곧바로 덮어쓰는 완성형 월드 에셋팩은 아님.
