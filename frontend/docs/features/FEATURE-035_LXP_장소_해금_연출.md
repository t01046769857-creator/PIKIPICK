# FEATURE-035 · LXP 장소 풍경과 해금 연출

## 확인 결과

현재 프로젝트에는 장소별 래스터 이미지와 별도 장소 해금 이벤트 데이터가 없었다. 기존 대시보드가 보유한 `roundCount`, `successCount`만 안전하게 사용한다.

## 구현

- 다섯 장소를 각각 독립적인 인라인 SVG 풍경으로 구성했다.
- 기록이 없으면 장소는 저채도 실루엣과 잠금 표시로 보인다.
- 해금 조건은 기존 진행값을 유지한다. 첫 놀이 기록은 새싹 언덕, 성공 1회 이상은 마법 샘, 성공 5회 이상은 무지개 다리까지다. 현재 데이터로 확인할 수 없는 구름 성·별빛 문은 잠금 상태다.
- 첫 진입 시 기존 기록을 과거 해금 이벤트로 재생하지 않는다. 기준점은 `pikipick.secret-land.unlock.v1`에 저장한다.
- 이후 해금 기준이 증가하면 축하 메시지 → 잠시 대기 → SVG 곡선 경로를 따른 피키 이동 → 도착 후 컬러 전환 순서로 실행한다.
- 지도에는 장소 이름만 표시하고 `발견했어요`·지원 상태 문구는 제거했다.

## 한계

장소 전용 원본 이미지와 상세 놀이 이벤트가 없으므로 SVG 풍경은 코드 내 벡터 일러스트다. 실제 장소별 이미지 에셋이나 세분화된 해금 이벤트를 도입하려면 별도 데이터·에셋 설계가 필요하다.

## 검증

`npm.cmd run build`, Vitest 57개, `git diff --check` 통과. 새 브라우저 프로필의 실제 화면에서 잠금 풍경·장소명·첫 추억 카드·중복 상태 문구 제거를 확인했다. 기록 증가에 따른 최초 해금 이동 시나리오는 자동 데이터 주입 없이 미검증이다.
