# FEATURE-025 개인 아동 중심 교사용 LMS 대시보드 데모

## 목적

교사 인증과 담당 아동 연결이 아직 구현되지 않은 상태에서, 실제 개인정보·TiDB 기록과 완전히 분리된 단일 아동 중심 LMS 화면을 확인할 수 있게 한다.

## 화면과 경로

- `/teacher/dashboard`: 기존 인증·담당 아동 연결 안내를 유지하고 `대시보드 데모 보기`를 제공한다.
- `/teacher/demo/child`: 가상 `아동 A`의 정적 데모 대시보드다.
- `/teacher/children/:id`: 기존 인증 전 접근 차단 화면을 유지한다.

## 구현

- `TeacherDemoDashboard.tsx`가 정적 세션 원본 데이터에서 참여, 시도, 목표 선택, 재도전 수치를 계산한다.
- 놀이 기록, 성취와 개인별 변화, 그림책 연계 활동의 세 영역만 표시한다.
- 배지는 데모 배지로 명시하며, 승패와 규칙 수행 성취를 분리해 안내한다.
- 그림책 영역은 실제 제목·표지·도서관 정보나루 API를 사용하지 않는 주제 중심 활동 예시다.
- 실제 API·TiDB·아동 개인정보·인증·담당 관계는 호출하거나 구현하지 않는다.

## 향후 연결 지점

인증과 권한 검증을 구현한 뒤에만 `TeacherDemoDashboard`의 정적 데이터 접근부를 담당 아동 권한이 확인된 API 응답으로 교체한다. 교사가 그림책과 후속 활동을 선택한 뒤에만 아이용 화면으로 전달하는 구조를 사용한다.

## 검증

- Vitest: 10개 파일, 58개 테스트 통과
- `npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과
- 실제 브라우저 반응형 육안 검증과 실제 인증·권한 연동은 아직 수행하지 않았다.
