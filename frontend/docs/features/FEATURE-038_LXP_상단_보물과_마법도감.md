# FEATURE-038 · LXP 상단 보물과 마법 도감

- 상단 왼쪽은 획득 배지를 최대 3개만 전시하는 보물상자 진열장으로 변경했다.
- 상단 오른쪽은 가방 이모지 버튼 대신 배지와 보물 장식이 있는 마법 도감 버튼으로 변경했다.
- 두 버튼은 기존 배지함 열기 콜백을 재사용한다.
- 실제 획득 배지는 기존 정렬·조건에서만 가져오며, 빈 상태에서는 빈 보물상자를 표시한다.
- 성공 횟수 변화로 진열장 컴포넌트가 갱신될 때 새 배지 등장 애니메이션을 실행한다.
- 모험길, 기록, API, DB, LMS는 변경하지 않았다.

검증: `npm.cmd run build`, Vitest 57개, `git diff --check`, Chrome 1440×900 실제 캡처 확인.

## 2026-11-19 · 배지함 UI 보완

- 활성 `LxpBadgeCollection`의 도감 제목 옆 피키는 기존 `curious` 표정을 기본으로 사용한다.
- 도감이 열린 상태에서 성공 횟수가 증가하면 `surprised`에서 `successHappy`로 이어지는 짧은 반응을 실행하며, 최초 입장 시 과거 획득 기록을 새 획득처럼 재생하지 않는다.
- 배지를 선택하면 피키 반응을 `curious`로 되돌린 뒤 기존 배지 상세 열기 콜백을 호출한다.
- `새 놀이 만나기` 버튼은 활성 배지함에서만 제거했다. 다른 화면과 레거시 컴포넌트의 공용 스타일·이동 흐름은 유지했다.
- 기존 배지 ID, 이름, 획득 조건, 정렬, 6개 단위 페이지네이션, 획득 판정은 변경하지 않았다. 데스크톱 3열·모바일 2열 도감 카드에 획득/잠금 상태의 시각적 차이와 동화풍 프레임을 보완했다.
- 현재 저장소에는 승인된 개별 배지 일러스트 PNG가 없어 기존 데이터 기반 CSS 배지 아트는 유지했다. 이를 실제 2D 삽화로 교체하는 작업은 별도 에셋 검수 후 진행해야 한다.

검증: 활성 배지함 Vitest 정적 렌더 테스트와 빌드 예정. 실제 브라우저의 클릭·반응 연출은 실행 환경 확인 후 별도로 검증한다.

## 2026-11-19 · 배지함 헤더·뒤로가기 레이아웃

- 배지함 경로에만 `story-back-row--badge-collection`을 부여해 공통 뒤로가기 행이 실제 높이를 차지하도록 했다. 제목 카드와 버튼이 겹치지 않으며 다른 화면의 뒤로가기 배치는 유지된다.
- 활성 `LxpBadgeCollection`에 전용 루트·헤더 클래스를 추가해 피키 표정과 도감 제목을 한 영역으로 정렬하고, 획득 카드와 잠금 카드의 프레임 대비를 보완했다.
- 배지 ID·조건·정렬·페이지 크기·저장 방식은 변경하지 않았다.
- 별도 2D 배지 일러스트 에셋은 현재 저장소에 없으므로 기존 CSS 기반 배지 아트를 유지했다. 실제 삽화 교체는 승인된 배지 PNG/SVG 에셋 확보 후 별도 작업이 필요하다.

## 2026-11-19 · 보물상자 배지 상승 레이어

- 첨부 설명용 빨간 X·노란 선·노란 동그라미는 구현하지 않았다.
- 활성 `TreasureDisplay`에서 실제 획득 목록의 첫 배지가 상자 중앙 내부에서 시작해 위로 상승하도록 기존 `lxp-treasure-badge-rise` 흐름을 유지·연결했다.
- RGBA 상자 PNG는 원본을 수정하지 않고, 동일 위치의 앞면 영역을 `lxp-secret__treasure-chest-front-mask` 레이어로 올려 배지 하단을 가린다. 상자 컨테이너는 `overflow: visible`로 유지해 상자 위 배지가 잘리지 않도록 했다.
- 빈 상자에는 배지 레이어를 추가하지 않으며, 기존 획득 데이터·정렬·상자 클릭 동작은 변경하지 않았다.
- 현재 배지 표현은 별도 승인 PNG가 없어 기존 `BadgeVisual`을 사용한다. 실제 배지 이미지 교체는 별도 에셋 검증이 필요하다.

검증: Vitest 59개 통과, `npm.cmd run build` 통과. 브라우저에서 출발·상승·도착 위치를 직접 캡처하는 검증은 현재 브라우저 자동화 도구 부재로 미실행.

## 2026-11-19 · 보물상자와 도감 클릭 분리

- `TreasureDisplay`는 `button`과 `onOpen` 콜백을 제거하고 일반 `section` 표시 요소로 변경했다.
- 보물상자에는 포인터 커서·키보드 클릭·도감 이동 접근성 역할을 부여하지 않는다.
- `MagicBadgeBook`만 기존 `onBadges` 클릭 및 키보드 접근성을 유지한다.
- 보물상자 클릭으로 배지 애니메이션이 재생되는 경로는 없으며, 배지 등장 시점은 기존 `successCount` 기반 렌더링/애니메이션에 한정된다.

검증: Vitest 59개 통과, `npm.cmd run build` 통과. 실제 브라우저 클릭 검증은 브라우저 자동화 환경 부재로 미실행.
