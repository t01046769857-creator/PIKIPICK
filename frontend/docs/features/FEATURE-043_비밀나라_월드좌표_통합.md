# FEATURE-043 — 비밀나라 월드 좌표 통합

## 목적

비밀나라의 배경 이미지, 장식 SVG, 목적지, 피키 이동 경로가 서로 다른 기준으로 움직이던 문제를 해결한다. 활성 모험 지도는 하나의 `2400 × 800` 월드 좌표를 사용하고, 피키는 배경에 보이는 길과 무지개 다리 위의 경로만 이동한다.

## 수정 파일

- `src/components/LxpSecretLandDashboard.tsx`
- `src/components/LxpSecretLandDashboard.css`
- `src/components/LxpSecretLandDashboard.test.tsx`
- `src/assets/secret-land/secretLandAssets.ts`

## 월드 모델

`adventureWorld`는 `{ width: 2400, height: 800, viewportWidth: 620, viewportHeight: 360 }`이다. 배경, 목적지 일러스트, 라벨, 피키 발 위치, 카메라가 이 좌표계를 공유한다.

| 장소 | landmark | pathAnchor (피키 발) | 비고 |
| --- | --- | --- | --- |
| 새싹 언덕 | 300, 505 | 250, 585 | 길 시작 구간 |
| 마법 샘 | 805, 455 | 820, 570 | 샘 앞 길 |
| 무지개 다리 | 1330, 430 | 1330, 410 | 다리 보행면 중심 |
| 구름 성 | 1745, 285 | 1760, 395 | 언덕길 |
| 별빛 문 | 2215, 345 | 2215, 470 | 마지막 길 |

무지개 다리는 `1155,475 → 1240,430 → 1330,410 → 1425,425 → 1490,455`의 왼쪽 접근·왼쪽 경사·보행면 중심·오른쪽 경사·출구 노드를 실제 이동 경로에 포함한다. 기존에 화면에 별도로 떠 있던 SVG 경로와 장식 SVG는 활성 월드에서 렌더링하지 않는다.

탐험가 피키 이미지는 원본 캔버스 `1460 × 1078` 비율로 렌더링하며, PNG 픽셀 분석으로 확인한 가장 낮은 부츠 접점 `(974,1025)`를 `footAnchor = { x: 974/1460, y: 1025/1078 }`로 사용한다. 이동 좌표는 이미지 박스의 중앙이나 캔버스 하단이 아니라 이 실제 접지점에 매핑되므로, 하단 alpha 여백과 `object-fit: contain` 오차를 제거한다. 개발 모드에서 URL에 `?debug=feet`를 붙이면 경로, 목표 접지점, 실제 접지점, 실제 화면 좌표 오차가 활성화된다.

## 에셋

- `secret-land-world-base-v3.png`: 길과 지형만 담당하는 3:1 월드 배경
- `place-*-v2.png`: 다섯 목적지의 독립 투명 일러스트
- `secret-land-treasure-chest-v2.png`: 상단 열린 보물상자
- `secret-land-badge-book-v2.png`: 상단 마법 배지 도감

이 이미지는 월드 상태를 저장하지 않는다. 해금, 기록, 배지 정렬, 클릭·터치 이동, 더블클릭 점프, 카메라 추적은 기존 React 상태와 저장 키를 그대로 사용한다.

## 검증

- `npm.cmd run build`: 통과
- `npm.cmd run test`: 11 파일, 58 테스트 통과
- Chrome headless 실제 화면: 1440×900, 1024×768, 390×844 확인
- 합성 기록 `successCount=5`에서 피키 위치가 `55.4167% → 35.4726% → 55.4167%`로 바뀌는 것을 확인해, 좌측 선택 후 마법 샘 이동과 우측 선택 후 무지개 다리 복귀를 검증했다.
- 무지개 다리의 `pathAnchor`와 접근·정상·출구 노드를 보행면 중앙으로 재조정해 피키가 상부 난간이나 수면이 아니라 다리 위에 서도록 보정했다.
- 기존 정사각형 이미지 박스와 실제 PNG 비율 불일치, 그리고 캔버스 하단의 alpha 여백을 확인하고, 원본 비율 기반 렌더링 및 실제 픽셀 접지점으로 수정했다. 디버그의 `screen Δ`는 모델 좌표가 아니라 실제 DOM 접지점과 SVG 목표점의 화면 중심 차이를 의미한다. 1440×900의 무지개 다리 중앙에서 약 `2.1px, 0.4px` 이내로 측정됐다.
- `?debug=feet&progress=`를 사용해 다리 진입·오르막·정상·내리막·출구를 각각 정지 캡처했고, 다섯 구간 모두 `screen Δ 0.0,0.0px`으로 확인했다.

## 남은 한계

실제 게임 기록으로 아직 해금되지 않는 구름 성·별빛 문의 장기 이동 연출은 현재 기록 규칙상 자동으로 재현하지 않았다. 새 콘텐츠가 추가되어 해금 규칙이 확장되면 동일 좌표 모델에 목적지와 경로 노드를 추가해야 한다.
