- 관련 기능: 초기 React/Vite 구조와 게임 상태
- 현재 상태: 과거 기록 — 현재 구현은 별도 문서로 갱신됨
- 마지막 확인일: 2026-11-12
- 관련 코드 위치: [`../src`](../src)
- 관련 문서: [개발 현황](DEVELOPMENT_STATUS.md) · [기능 문서](features/README.md)

> 이 문서는 초기 기록입니다. 피키 에셋이 “미확정”이라는 일부 서술은 현재와 다를 수 있으므로, 최신 상태는 `DEVELOPMENT_STATUS.md`와 기능 문서를 우선합니다.

## 새롭게 시도한 기술

- Vite + React + TypeScript 기본 구성을 만들었습니다.
- `useReducer`로 게임 단계를 명시적으로 관리했습니다.
- Vitest로 순수 규칙과 상태 전이를 자동 테스트하도록 했습니다.

## 재사용한 방식

- 게임 데이터를 문자열 union 타입으로 제한해 입력값을 단순하고 읽기 쉽게 유지했습니다.
- 화면과 계산 로직을 별도 파일로 나누고, 작은 컴포넌트로 반복 UI를 분리했습니다.

## 문제와 해결

- 중복 클릭으로 성공이 여러 번 올라갈 수 있는 문제를 `phase === 'PLAYING'` 및 `result` 확인으로 차단했습니다.
- 별 5개 표시와 실제 성공 횟수가 달라질 수 있어 숫자는 계속 누적하고 UI는 표시 칸만 잘라 보여주는 구조로 분리했습니다.
- 피키 캐릭터가 확정되지 않아 실제 이미지는 만들지 않고 교체 가능한 임시 영역만 두었습니다.
- 기존 프로젝트 루트에 Git 저장소가 없어 Git 초기화나 커밋은 수행하지 않았습니다.
