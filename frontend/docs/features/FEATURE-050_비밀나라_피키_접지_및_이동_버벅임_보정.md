# 비밀나라 피키 접지 및 이동 버벅임 보정

## 목적

피키의 발 접지 기준이 실제 통합 월드의 흙길·무지개 다리 보행면과 일치하도록 경로 기준을 정리하고, 이동 중 CSS 보간과 회전 흔들림으로 인한 시각적 버벅임을 제거한다.

## 변경 파일

- `frontend/src/components/LxpSecretLandDashboard.tsx`
- `frontend/src/components/LxpSecretLandDashboard.css`

## 구현 방식

- 기존 2400×800 월드와 12개 경로 노드 구조는 유지했다.
- 원본 월드 PNG의 실제 흙길·석재 데크 중심을 픽셀로 대조해 기존 경로의 y좌표와 목적지 `pathAnchor`를 필요한 지점만 보정했다.
- idle/left/right PNG의 실제 알파 영역 하단을 확인했다. 기존 footAnchor는 각 이미지의 부츠 하단 바로 아래 기준점으로 유지했다.
- rAF로 갱신되는 캐릭터 위치에 CSS `left/top` transition을 중복 적용하지 않도록 했다.
- 이동 중 이미지에 적용되던 ±1도 회전 애니메이션을 제거해 발 접지 높이가 흔들리지 않게 했다.
- 월드 카메라 transform에도 CSS transition을 적용하지 않아 캐릭터와 배경 업데이트 시점이 어긋나지 않게 했다.

## 검증

- PNG 알파 영역 및 발 하단 픽셀 검사 완료
- `?debug=feet`의 DOM 목표점/접지 표시를 목적지 5개 구간에서 확인
- 1440px 브라우저 캡처에서 무지개 다리 중앙 피키의 부츠와 보행점 높이 확인
- 테스트 12개 파일, 63개 통과
- `npm.cmd run build` 통과

## 남은 문제

실제 사용자 계정의 해금 기록별 이동 시나리오는 별도 운영 데이터가 필요하다. 현재 검증은 개발 브라우저의 디버그 좌표와 임시 테스트 세션으로 수행했으며, 테스트 후 브라우저 저장값은 원래 값으로 복원했다.
