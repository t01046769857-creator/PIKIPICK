# FEATURE-046 — 비밀나라 카메라 확대 및 피키 주변 흐림 보정

## 문제와 원인

- 승인된 월드는 `2400 × 800`이지만 카메라 논리 뷰포트가 `620` 월드 단위로 고정되어 데스크톱에서 실제 화면의 좁은 구간만 크게 보였다.
- 피키 PNG에는 하단의 흰 구름 장식이 원본으로 포함되어 있다. 별도로 CSS `drop-shadow`도 적용되어 가장자리가 부드럽게 번져 보일 수 있었다.
- 모바일에서는 데스크톱과 같은 논리 폭을 사용할 때 월드의 계산 높이가 지도 뷰포트보다 작아 하단 단색 영역이 생길 수 있었다.

## 변경 파일

- `frontend/src/components/LxpSecretLandDashboard.tsx`
- `frontend/src/components/LxpSecretLandDashboard.css`

## 변경 내용

- 월드·경로·목적지 좌표는 변경하지 않고 카메라 논리 폭을 `840`으로 넓혔다.
- 반응형 카메라 폭을 적용했다.
  - 데스크톱: `840`
  - 태블릿: `780`
  - 모바일: `680`
- 카메라의 X 좌표와 클릭 좌표 계산 모두 같은 논리 폭을 사용하도록 맞췄다.
- 모바일 카메라의 세로 초점을 `.72`로 낮춰 제목 패널과 피키가 겹치지 않게 했다.
- 탐험가 PNG의 원본 구름 장식은 유지하고, CSS `drop-shadow`만 제거했다.
- 승인 배경 이미지, 이동 경로, 피키 이미지, 게임/API/DB는 변경하지 않았다.

## 남은 한계

- 피키 PNG 원본에 포함된 흰 구름 장식은 캐릭터 에셋의 일부이므로 제거하지 않았다.
- 현재 목적지 아트는 카메라 구간에 따라 가장자리에서 부분적으로 보일 수 있으며, 이번 변경에서는 목적지·경로 좌표를 수정하지 않았다.
