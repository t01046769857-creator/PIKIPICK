# FEATURE-032 개인 담당자 LMS 대시보드

## 구현 범위

- 기존 `/teacher/dashboard`와 `/teacher/children/:id` 주소를 유지했다.
- 교사 토큰과 승인된 `HOME_PLAY_HISTORY` grant를 통과한 `/api/manager/children/:id/home-dashboard`만 실제 기록을 반환한다.
- DB 스키마 변경 없이 API 응답에 기간 요약, 콘텐츠별 지표, 일별 추이, 요일별 분포, 규칙별 선택, 손동작 분포, 원본 이벤트, 계산 근거를 추가했다.
- 프론트는 2열 콘텐츠 그리드, 상단 요약 카드, 탭 전환, 우측 sticky 분석 상세 패널로 구성했다.
- 검증된 누리과정 출처 매핑과 점검 메모 저장 API는 아직 없으므로 `미지원`으로 표시한다.

## LXP 확장 구조

- 전체 놀이 경험 탭은 참여 추이, 승인된 이벤트 타임라인, 새로운 경험 후보, 그림책 주제 연결을 공통으로 표시한다.
- 콘텐츠별 분석 탭은 `/api/content-catalog` 상태와 `frontend/src/teacher/contentAnalytics.ts`의 분석 모듈 레지스트리를 함께 사용한다.
- 현재 `rock-paper-scissors`만 실제 분석 모듈이며, 나머지 카탈로그 항목은 `COMING_SOON`으로만 표시한다.
- 새 콘텐츠는 카탈로그 정의와 자신의 분석 모듈을 추가해 공통 대시보드 레이아웃을 재사용할 수 있다.

## 권한과 데이터 보호

담당 아동 목록은 인증된 담당자 API에서 가져오며, 대시보드 본문은 승인된 HOME 기록만 표시한다. 승인 철회·만료·비담당 아동은 서버에서 차단한다. 주소만 직접 입력해도 프론트가 합성 데이터를 대신 노출하지 않는다.

## 검증

- 실제 Chrome에서 담당자 로그인 후 대시보드 렌더링 확인
- 1440×900: `952px 310px` 2열 레이아웃 확인
- 390×844: 단일 열 재배치 확인
- 탭 4개, 요약 카드 4개, 분석 근거 선택 패널과 계산식 표시 확인
- 프론트 빌드 및 Vitest, 백엔드 회귀 테스트 통과

## 미구현

누리과정 공식 출처 매핑, 담당자 메모 영구 저장, 실제 그림책 결과 API는 별도 승인·데이터 모델 검토가 필요하다.
