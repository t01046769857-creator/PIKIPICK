# FEATURE-020 · 다중 놀이 선택 화면

## 목적

가위바위보의 기존 모드 선택 화면 앞에 전체 놀이 선택 화면을 추가했다. 가위바위보는 기존 이기기·지기·비기기·규칙 연습 화면으로 이어지고, 아직 구현되지 않은 다섯 놀이는 준비 중 안내만 표시한다.

## 화면 흐름

`메뉴의 놀이 선택` 또는 인트로 시작 → `전체 놀이 선택` → `가위바위보` → 기존 `모드 선택` → 기존 게임 플레이

기존 모드 선택 화면의 뒤로가기는 전체 놀이 선택 화면으로 돌아간다. 다른 메뉴에서 기존 모드 선택 화면으로 직접 진입하지 않도록 메뉴의 놀이 선택 목적지를 전체 놀이 선택으로 변경했다.

## 구현 방식

- `ACTIVITY_SELECT` 게임 상태와 `OPEN_RPS_MODE_SELECT` 전환을 추가했다.
- 카드 정보는 `ActivitySelection.tsx`의 `activities` 배열에서 ID, 이름, 그림, 상태, 색상으로 관리한다.
- 가위바위보 카드만 기존 `MODE_SELECT` 상태로 이동한다.
- 나머지 카드는 피키와 함께 “곧 만나요!” 안내를 표시한다. 실제 게임·결과·기록을 만들지 않는다.
- 새 화면 전용 CSS는 `ActivitySelection.css`의 `.activity-*` 범위로 제한했다.

## 유지한 기능

기존 가위바위보 2×2 모드 카드, 공식 손 에셋, 판정 reducer, 별 보상, 기록 저장과 재전송, FastAPI와 TiDB는 변경하지 않았다. 청개구리 콘텐츠는 새 카드에 포함하지 않았다.

## 카드 그림 구성

전체 놀이 선택 화면은 공식 피키 캐릭터와 독립 손 PNG를 재사용한다. 프로젝트에는 다른 놀이 전용 이미지가 없으므로 외부 아이콘이나 이미지를 추가하지 않았다. 묵찌빠는 마주 보는 손동작, 손가락 수 세기는 편 손과 수 세기 점, 숫자 놀이는 사과 모양 수량, 패턴은 반복 도형, 그림책 놀이는 피키와 CSS로 구성한 펼친 책으로 표현한다. 이 그림 요소는 전체 놀이 선택 화면에만 적용된다.

## 확인 항목

- 전체 놀이 선택 카드 6개와 준비 중 안내
- 전체 놀이 선택 → 가위바위보 → 기존 모드 선택 전환
- 모드 선택에서 뒤로가기로 전체 놀이 선택 복귀
- reducer 단위 테스트와 프론트엔드 빌드
