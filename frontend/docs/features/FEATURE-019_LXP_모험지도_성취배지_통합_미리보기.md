# FEATURE-019 · LXP 모험 지도·성취 배지 통합 미리보기

## 목적

기존 가위바위보 기능을 바꾸지 않고, 5~7세 유아가 놀이 경험을 탐험으로 느낄 수 있는 모험 지도와 성취 배지의 화면 방향을 검토할 수 있도록 독립 React 미리보기를 만들었다.

## 실행 방법

```powershell
cd frontend
npm run dev
```

브라우저에서 `http://localhost:5173/lxp-preview.html`을 연다. 이 주소는 기존 게임 시작 주소와 별도이며, 개발 서버가 실행 중인 경우에만 사용할 수 있다.

## 구현 파일

- `frontend/lxp-preview.html`: 미리보기 전용 Vite 진입 HTML
- `frontend/src/lxp-preview.tsx`: 미리보기 React 진입점
- `frontend/src/preview/LxpAdventurePreview.tsx`: 장면 상태와 인터랙션
- `frontend/src/preview/LxpAdventurePreview.css`: 미리보기 전용 반응형 스타일

기존 `App.tsx`, 게임 상태·판정, FastAPI 라우터, TiDB 모델·마이그레이션은 변경하지 않았다.

## 포함한 장면

1. 처음 모험 지도
2. 배지와 새 길을 발견한 지도
3. 상단 별 기록판 대신 작은 배지 주머니를 둔 가위바위보 놀이 화면
4. 새 배지 획득 축하
5. 배지 모음
6. 선택한 배지 상세와 획득 이유
7. 새 탐험 공간이 열리는 장면

각 장면은 상단 장면 선택 버튼과 화면 안의 이동 버튼으로 확인할 수 있다. 가위바위보 손은 프로젝트의 공식 피키 손 PNG를 사용하고, 피키 표정도 기존 캐릭터 에셋을 재사용한다.

## 데모 데이터와 보존 원칙

모든 배지·길·카운트는 컴포넌트 내부의 고정 데모 상태다. 화면에 `데모 미리보기 · 실제 기록과 연결되지 않아요`를 표시한다. 실제 저장 데이터, 별 보상, 게임 기록, 사용자 계정 또는 권한을 읽거나 쓰지 않는다.

배지 설계는 첫 놀이, 재도전, 실패 뒤 성공, 반복 참여, 새 활동, 활동 다양성, 규칙 이해, 특별 활동, 새 구역 발견을 구분한다. 재시도나 실패는 획득한 배지와 발견한 공간을 제거하지 않는 방향으로 표현했다. 배지는 모든 콘텐츠를 잠그기 위한 조건이 아니라, 놀이 경험을 기억하는 수집 요소다.

수 세기·패턴 길·그림책 숲은 향후 확장 구역으로만 표기했으며, 실제로 열리거나 실행되는 기능은 아니다. 청개구리 콘텐츠는 포함하지 않았다.

## 후속 구현 전 검토가 필요한 항목

- 디자인 승인 후 실제 게임 화면의 별 기록판을 배지 주머니 흐름으로 바꾸는 범위
- 배지 조건을 실제 세션·이벤트 데이터와 연결하는 서버 설계
- 교사용 URL(`/teacher/login`, `/teacher/dashboard`)과 역할 인증·권한 구현
- 실제 콘텐츠가 생긴 뒤 수 세기·패턴·그림책 구역의 진입 흐름

위 항목은 이번 미리보기에 구현하지 않았다.
