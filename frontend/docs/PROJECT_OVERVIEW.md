## 무엇을 만드는 프로젝트인가요?

PIKIPICK은 유아가 피키 캐릭터와 함께 가위바위보를 하는 React 기반 놀이 화면입니다. 아이는 피키의 손을 눌러 놀이를 시작하고, 이기기·지기·비기기 중 하나를 고른 뒤 큰 손동작 버튼으로 답합니다.

## 현재 구현 범위

| 영역 | 현재 확인된 구현 | 상태 |
|---|---|---|
| 시작 인트로 | 단계형 피키 등장, 말풍선, 손 클릭 시작, 브라우저 음성 선택 | 개발 중 |
| 가위바위보 규칙 | WIN/LOSE/DRAW 3개 모드와 27조합 테스트 | 구현됨·미검증 |
| 게임 진행 | 준비 → 문제 → 결과 → 약 1.7초 뒤 자동 다음/재도전 | 구현됨·미검증 |
| 보상 | 성공 1회당 별 1개, 5회마다 파티 수 증가 | 구현됨·미검증 |
| 기록 | `localStorage`에 성공 수와 파티 수 저장 | 구현됨·미검증 |
| 성능 계측 | 개발 모드에서 입력/화면 반영/다음 문제 시간 집계 | 구현됨·미검증 |
| AI 입력 | `AI` 입력 형식만 예약됨. 웹 카메라·FastAPI 연결 없음 | 계획 |

## 일부러 포함하지 않은 범위

- MediaPipe Python 코드는 React 화면과 연결되어 있지 않습니다.
- MySQL, 로그인, 부모·교사 대시보드는 코드에서 확인되지 않습니다.
- 청개구리 모드는 화면에 “준비 중”으로만 표시되며 규칙은 구현되지 않았습니다.
