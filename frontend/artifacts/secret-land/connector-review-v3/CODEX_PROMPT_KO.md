## 파일/좌표
- `reference/`: 무지개 다리 승인 원본(2400×800) 및 기존 좌우 원본(3100×900, 3500×900) — 변경 금지
- `assets/*-v3-REVIEW.png`: 왼쪽/오른쪽 국소 보정 후보(원본 규격 유지)
- `previews/`: x3100 및 x5500 이음새 확대, 전체 9000×900 보기
- `manifest.json`: 배치 좌표 및 보정 범위

현재 런타임의 `connectors-review-v1` 및 기존 승인 다리 원본을 덮어쓰지 마세요. 새 후보는 우선 격리된 검수 폴더에 놓으세요.

## 검수 순서
1. PIL 또는 이미지 검사 스크립트로 PNG 크기: 3100×900, 3500×900, RGB 확인.
2. 왼쪽 후보 x0~2599, 오른쪽 후보 x500~3499가 기존 원본과 픽셀 완전히 동일한지 확인.
3. 무지개 다리 자체는 project 원본 SHA-256이 변경되지 않았는지 확인.
4. 경계 x3100, x5500 색상 차이와 **육안상** 흙길·강둑·물가·나무·원경 연결을 함께 검토.
5. world y50~850에 놓이는 무지개 다리 상하 50px 여백 처리 검토. 미리보기의 가장자리 단순 연장은 게임 최종 아트가 아닙니다.
6. 가장 중요한 부분: 실제 x3100의 경로노드 9 y690와 원본 그림 속 길 중심 약 y603.5 간 오차를 검증. 경로 보정이 필요하면 보행 시간 15~20초와 평지/다리 접지에 영향이 없는 작은 노드 조정안을 작성해 승인 후 적용하세요.
7. 연결부가 자연스럽지 않다면 기존 CSS 지형 유지, 새 배경 적용 보류. 어색한 픽셀/월드 좌표 및 캡처 제공.
8. 통과할 경우에만 새 연결 배경을 런타임에 반영하고 중복 CSS 지형을 비활성화. 1440×900, 1024×768, 390×844에서 평지·다리 양방향·정지·카메라·해금/저장 검증. Build/Vitest 실행.
