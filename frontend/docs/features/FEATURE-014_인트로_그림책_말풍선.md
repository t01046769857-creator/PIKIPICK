# FEATURE-014 — 첫 화면 그림책 말풍선

- 날짜: 2026-11-13
- 목적: 첫 화면의 큰 초대 말풍선과 작은 손 터치 안내만 피키와 어울리는 그림책 스타일로 변경한다.
- 변경 파일: `src/components/PikiSpeechBubble.tsx`, `src/components/PikiIntroScene.tsx`, `src/styles.css`.
- 검증 자료: [`screenshots/intro-bubbles/`](../screenshots/intro-bubbles/).

## 디자인과 구현

기존 피키 초대 포즈와 실제 화면을 확인한 뒤, 래스터 캐릭터 이미지를 수정하지 않고 SVG 곡선으로 말풍선 외곽을 그렸다. 큰 말풍선은 크림색 구름 형태와 아래쪽 곡선 꼬리, 작은 말풍선은 옅은 분홍색 구름 형태와 손을 향하는 위쪽 꼬리를 사용한다. 두 말풍선 모두 굵은 갈색 선과 읽기 쉬운 HTML 텍스트를 사용한다. SVG에는 장식·문자·그림자를 넣지 않는다.

`PikiSpeechBubble`에 `invitation`/`hand` 변형을 추가했다. 큰 문구 “나랑 같이 놀자!”를 유지하고 작은 안내는 “히히! 내 손 잡아볼래?”로 교체했다. 기존 반짝이 세 개와 알약형 라벨을 제거했다.

두 말풍선은 기존 캐릭터 캔버스에 절대 위치로 배치한다. 큰 말풍선의 입장 효과는 내부 그림에만 적용해 외부 위치 정렬 transform과 충돌하지 않게 했다. 작은 말풍선은 그림만 1.75초 주기로 최대 3px 위아래 움직이며, 캐릭터·손 자체의 애니메이션은 수정하지 않는다. 두 말풍선 모두 pointer-events가 none이어서 손 터치를 가로막지 않는다. reduced-motion에서는 말풍선의 입장·유도 움직임을 끈다.

PC·태블릿에서는 작은 말풍선을 손 왼쪽에 배치하고 화면 경계에서 위치를 제한한다. 모바일에서는 폭과 세로 글 영역을 조정해 두 줄 문구가 테두리 안에 들어오도록 했다. 낮은 가로 화면은 말풍선 전용 위치를 사용해 기존 로고·하단 안내와 겹치지 않게 했다. CSS는 기존 말풍선 규칙을 교체하고 `.intro-v2` 아래로 제한했다.

## 보호 범위

`PikiIntroScene` 변경은 작은 안내 JSX 한 곳뿐이다. `phaseDuration`, 빼꼼→손 내밀기 전환, `beginPlay`, 투명 손 버튼, 음성 동작은 수정하지 않았다. 캐릭터 에셋·크기·위치·배경·로고·메뉴·게임 화면 및 손 파츠도 변경하지 않았다. 파일 삭제, Git 커밋·푸시는 실행하지 않았다.

## 검증 결과

- 실제 Chrome headless로 수정 전 Before 5장과 검증된 최종 After 5장을 확보했다. 중간 작업 화면을 Before로 사용하지 않았다.
- 해상도: 1440×900, 768×1024, 390×844, 320×740, 844×390.
- 최종 두 말풍선이 각 뷰포트 안에 들어오는지 검사하고 캡처에서 텍스트와 꼬리·테두리를 직접 확인했다.
- Before/After 측정으로 캐릭터 캔버스·몸 이미지·로고·메뉴·하단 안내의 x/y/width/height가 모두 동일함을 확인했다(허용 오차 0.1px).
- 다섯 화면에서 손 터치 위치의 실제 hit-test를 통과하고 손 클릭 후 놀이 선택 카드 4개로 이동하는 것을 확인했다.
- 모바일 reduced-motion에서 두 말풍선·손의 애니메이션 중지 및 손 클릭 이동을 추가 확인했다.
- `npm run build`, `npm test`(5개 파일·31개 테스트), `git diff --check` 통과.

캡처와 측정 JSON, 재현 스크립트는 위 검증 자료 폴더에 있다. 실물 터치 기기의 조작감과 모든 임의 화면 크기는 미검증이다. 높이 390px 가로 화면에서 기존 캐릭터 발끝·하단 안내의 배치는 수정 전 상태를 보존했다. 이번 작업은 말풍선만 조정했다.
