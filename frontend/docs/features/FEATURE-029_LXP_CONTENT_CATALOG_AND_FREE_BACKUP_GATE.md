# FEATURE-029 — LXP 콘텐츠 카탈로그와 무료 백업 적용 게이트

## 목적

가위바위보를 첫 번째 정식 콘텐츠로 유지하면서, 준비 중인 묵찌빠·손가락 수 세기·숫자·패턴·그림책 놀이를 실행 가능한 기능처럼 표시하지 않는 공통 콘텐츠 계약을 추가했다.

## 구현

- `backend/content_catalog.py`: 콘텐츠 ID, 상태, 허용 이벤트, 콘텐츠별로 의미 있는 지표 키, 그림책 주제를 정의한다.
- `GET /api/content-catalog`: LXP 화면과 이후 CMS가 사용할 공개 메타데이터를 제공한다.
- `backend/main.py`: 실행된 콘텐츠의 이벤트 유형을 버전 설정과 콘텐츠 계약 모두에서 검증한다.
- `backend/tests/test_api.py`: 가위바위보만 `PLAYABLE`이고 묵찌빠가 `COMING_SOON`임을 검증한다.

이 카탈로그는 DB의 공개 여부나 버전을 변경하지 않으며, 아직 CMS 관리 화면·콘텐츠별 실행기·추천 결과를 자동으로 만들지 않는다.

## 공용 TiDB Starter 적용 게이트

공용 DB에는 LMS/기관 세션 마이그레이션을 적용하지 않았다. Starter 무료 환경에서는 다음 증거가 확보된 뒤에만 비파괴적 적용을 검토한다.

1. TiDB Cloud Console 또는 CLI에서 SQL 논리 내보내기를 생성한다.
2. 별도 Starter 또는 로컬 MySQL 호환 테스트 스키마에 가져와 테이블, 행 수, 외래키와 기존 저장 API를 검증한다.
3. 복원 결과와 내보내기 시각, 대상 환경, 실행자, 검증 결과를 운영 기록에 남긴다.
4. 복원 가능한 백업이 확인된 뒤에만 `0002_teacher_lms`, `0003_institution_sessions`을 적용한다.

자동 백업의 보존 기간, 수동 내보내기와 별도 복원 대상의 실제 사용 가능 여부는 운영자가 TiDB Cloud Console에서 확인해야 한다. 이 프로젝트에는 Cloud Console 권한이나 격리된 MySQL/TiDB 대상 접속정보가 없으므로, 이 문서는 공용 DB 변경 완료를 뜻하지 않는다.

## 개인정보·권한 경계

- HOME 기록은 기관 LMS 조회에서 제외한다.
- INSTITUTION 기록은 서버가 발급한 제한시간 토큰, 담당 교사 배정, 기관 소속을 모두 확인한 경우에만 생성한다.
- 만 14세 미만 아동의 개인정보 처리에 필요한 법정대리인 동의·확인 방식, 보존 기간, 철회·삭제 정책은 서비스 운영 주체와 법률 검토 후 확정해야 한다. 코드만으로 법적 적합성을 선언하지 않는다.

## 검증

- 로컬 SQLite API 테스트에서 카탈로그 상태와 기존 세션/이벤트 동작을 함께 검증한다.
- TiDB Starter 복원 검증과 공용 마이그레이션은 미실행이다.

## 후속 구현 (격리 환경)

- `backend/content_analysis.py`는 가위바위보의 원본 `round_result` 이벤트만으로 시도·목표에 맞은 선택·목표에 맞지 않은 선택을 계산한다. 재도전은 기존 이벤트에 신뢰할 수 있는 표시가 없으므로 미지원으로 남긴다.
- `backend/content_recommendations.py`는 실제 기록된 최신 콘텐츠를 그림책 주제로 연결한다. 아직 실행 가능한 다른 콘텐츠가 없으므로 준비 중인 카드로의 다음 놀이 추천은 생성하지 않는다.
- 교사용 대시보드 응답은 콘텐츠별 계산 결과와 그림책 주제를 포함하지만, 외부 도서 API가 검증·사용 가능할 때만 실제 도서 결과를 별도 요청해야 한다.
